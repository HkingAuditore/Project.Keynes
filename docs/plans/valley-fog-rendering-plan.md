# 地形约束的谷雾渲染方案

2026-11-29 · 实施计划。现状基线为 `63b8bd528`；下文的谷雾数据、材质接入和测量均为拟实施工作。

## 目标画面

清晨，一条河谷的两个村庄笼在薄雾里，中间的小山脊露出雾面。把空中云团隐藏，仍能沿雾的边缘读出坡脚与谷口。平移镜头时雾留在谷中，只有边缘随风缓慢起伏。拉远后，城市、道路和国界仍应容易辨认。

首版在现有二维天气覆盖层内绘制。后台按天气发布频率算每格的雾密度与雾顶；GPU 每帧根据真实地表高度求局部厚度。首版预算为一份低分辨率格点数据及其前后帧、零新增屏幕 RT、零新增全屏绘制调用。所有性能收益均待实测。

## 数据流与算法

| 时机 | 执行方 | 输入 → 输出 | 生命周期 |
|---|---|---|---|
| 生成、恢复或替换地形 | 地图烘焙 | 陆地掩码、海拔 → 局部谷底、凹陷程度 | 与地形版本一致 |
| 提交天气 | 后台气候模块与发布端 | 同一次天气求解的湿度、风、地形参考 → 每格密度和雾顶 | 一份不可变发布帧 |
| 收到有效新帧 | 地图渲染绑定 | 已发布字段 → 雾纹理及前后帧层号 | 原子切换，镜头平移时复用 |
| 每个可见天气像素 | 天气材质 | 雾场、地表高度、当地日照、风动纹理 → 雾颜色及透明度 | 随现有天气覆盖层一次输出 |

### 1. 烘焙局部地形参考

在后台按格预计算局部谷底高度和积雾倾向。以两到三圈六边格为初始窗口，取陆地高度的较低分位数估计局部谷底；取周围平均陆地高度与中心高度的差估计凹陷程度。平原保留较弱的基础积雾倾向。窗口横向回绕，南北按现有地图边界裁切。海底样本从陆地统计中排除，纯水域首版不生成谷雾。窄山脊能否露出取决于第三步的像素高度，窗口无需刻画每条山脊。

静态参考与渲染高度须使用同一归一化基准。生成、缓存命中、读档重建三条入口均应获得等价参考值；地形高度资源替换时一起失效。原型先用同一条山谷比对窗口半径与分位数，观察是否跨越分水岭把两个盆地连成一片。

### 2. 天气提交时发布每格雾场

雾密度由空气接近饱和的程度主导。复用气候内核的相对湿度定义，温度通过水汽容量参与。弱风提高积雾倾向，强风削弱谷雾；地表湿度经核对字段语义后只作为湿润河谷的小幅加成。云量不设起雾门槛。阈值应根据当前生产气候场的分布定标，避免照搬现实相对湿度阈值后整张图都不起雾。

雾顶由局部谷底高度加积雾厚度得到。潮湿、弱风、凹陷较深时允许厚度增加；平原应能产生薄雾。雾顶控制范围，密度控制透射率，两者独立调节。无雾格将密度置零，并保留当地有效的参考高度，防止插值时把相邻雾面拉向海拔零点。

后台随已提交天气发布同一代的格点数据。渲染端只读该帧，复用天气插值系数，格间沿用三格重心权重。优先以独立双通道格点数据纹理验证，前后帧仅在发布时轮换。编码需保证与地表高度的量纲一致，雾顶精度以缓坡上无可见台阶为准。首帧和载入后的首帧将前后帧都指向同代数据，防止跨地图或跨读档淡入。派生显示量可从已提交状态重建，不引入影响次日模拟的雾状态。

**原型参数化。** 用四个可单独观察的中间量定标：湿度门控、弱风权重、凹陷权重、积雾厚度。建议从以下关系开始，所有系数在固定种子样本上确定。地表湿润度和晨昏调制放在基础模型通过验证之后单独对照。

```text
湿度门控 = smoothstep(成雾起点, 充分成雾点, 相对湿度)
弱风权重 = 1 - smoothstep(弱风阈值, 消散风速, 已提交风速)
成雾势 = 湿度门控 × 弱风权重
积雾厚度 = 成雾势 × mix(平原厚度, 盆地厚度, 凹陷权重)
雾顶高度 = 谷底参考高度 + 积雾厚度
雾密度 = 最大消光系数 × 成雾势
```

先统计代表性种子中相对湿度与风速的联合分布，分别观察山谷、开阔平原、高原盆地和强风山口。固定地形和风只改湿度，再固定地形和湿度只改风；每次只校准一组参数。密度与厚度都含成雾势，若中等湿度区间几乎无雾，先查看两者乘积的消光曲线，再决定把哪一响应调平。记录输入分位数、参数、截图和雾区面积比例，使效果可复现。

**发布契约。** 优先沿用现有帧携带的世界身份、地形版本、天气代号和地图尺寸。R 为非负的归一化密度，G 为与地表解码同单位的雾顶；最大消光系数在编码或解码时只应用一次。采用 offset 格坐标、线性数据格式，禁用颜色空间转换。记录每代是否存在正密度格，用于整帧跳过。资料缺失时可以继续绘制现有天气。尺寸或数据长度错误、非有限值、过期代号和跨世界绑定均须在提交前拒绝，避免半张新图混入当前帧。同代重复发布保持幂等。若前台跨过多代，只接收配套天气与雾帧，失去连续前帧时从最新帧直接显示。切到低档时只释放或停用渲染资源，画质选择不得改变后台天气结果。

### 3. 天气覆盖层逐像素求透射率

在高档天气变体复用已计算的世界坐标与格点插值结果。取像素处地形高度，沿已发布局地风推动一层低频、可横向平铺的边缘扰动。扰动振幅限制在薄雾厚度的一小部分，使雾团主体仍受盆地约束。

```text
局部厚度 = max(雾顶高度 + 边缘扰动 - 像素地表高度, 0)
光学厚度 = 雾密度 × 局部厚度 × 高度单位换算系数
雾透明度 = 1 - exp(-光学厚度)
```

俯视镜头用垂直厚度近似光程。雾色取当地昼夜环境光。可在有雾势处用已有当地昼夜相位轻微调节晨昏外观，避免全图同一时刻起雾。物件与地表共用此处的雾厚，因此首版能表现山脊穿雾，树冠、屋顶穿雾需要另行提供物件高度。

### 4. 在同一绘制调用内合成

将谷雾作为天气材质的底层，再按透明度叠加主云与卷云，最后按当前 Canvas 混合约定输出一次颜色和透明度。内部可用预乘颜色累计，输出前适配现有 `blend_mix`，防止薄雾边缘重复乘透明度。保留雨雪幕自己的绘制次序。

同时检查天气层可见性、天气采样提前返回和 `has_layer` 判定。无云、无降水但有谷雾时仍须绘制；玩家视野门关闭的区域应屏蔽实时雾况。新旧格点路径与普通、分块地图须遵守相同坐标和可见性语义。沿用低、中档编译裁剪及 Web 整层开关，确保关闭档位不采高度、不更新专用 GPU 资源。跨档时从最新发布帧恢复。

## 雾面的体积与运动

原型使用一张可平铺、带 mipmap 的二维噪声纹理。R 存低频起伏，G、B 存同一高度噪声在两个纹理轴上的有符号斜率，A 存较细的雾丝。离线生成导数，纹理按线性数据读取。格点雾顶控制整片雾的位置；噪声只使表面起伏。将风速转换为有上限的世界位移，沿现有双相位流动函数采样两次，同权重混合高度、斜率和细节。两相位错开重置，避免风场变化时按累计时间突然跳位。横向平铺周期需整除世界周长，旋转或拉伸采样轴时使用同一雅可比变换恢复世界方向斜率。

厚度先决定透射率。谷底厚雾柔化地物，坡面露头处渐薄。再将起伏的两个斜率与竖直分量组成近似雾面法线，用当地太阳方向给日照色加一小段有界亮度差，基础雾色保留环境光。太阳很低时迎光、背光差最容易看见；夜侧随直射强度收敛。细节通道只在中间透射率区间略调密度，并随像素覆盖的世界尺度逐渐淡出，防止远景闪烁。光照幅度以侧光下仍像柔软雾层为上限。该近似支持俯视时的厚薄、前后遮蔽和流动纹理，无法重建水平视线下的自阴影或穿雾光柱。

## 性能预算与取舍

| 环节 | 首版工作量与验证方式 |
|---|---|
| 地形、发布 | 地形邻域只在生成或地形更新时处理。每个天气提交只编码一代雾场，前后台共用发布代号；镜头运动不触发上传。若选 RG16F，双缓冲格点纹理本体占用为格数 × 8 字节，不含传输暂存。 |
| 高档有雾像素 | 普通高度路径一次高度读取，双相位两次噪声读取，同时取得形状和斜率。复用天气的格点坐标只节省寻址；采用独立雾场时，三格空间插值乘前后两帧仍需最多六次格点读取。另计消光、光照、分块寻址和原有天气成本。 |
| 替换与裁剪 | 替换旧低雾的两相位云密度求值，移除仅为旧低雾服务的山地权重读取。低、中档编译掉新采样器与计算。整帧前后两代密度均为零时，可借发布摘要选择无雾路径，保留仍有贡献的过渡帧；棋盘式逐像素分支不计作稳定收益。 |
| 测量与降级 | 同镜头分别测基础厚度、加双相位、加方向光三组。固定晴空与满云两种背景，比较近景、远景，以及无雾、局部雾和满屏雾。若瓶颈在格点读取，先优化数据布局；若在噪声带宽，先试单相位简化档并检查跳变；只有屏幕像素成本占主导时才评估低分辨率 RT。 |

## 实施顺序与验收

1. **先验证轮廓。** 固定一幅含河谷和细山脊的地图，输入可控的恒定雾顶、密度，隐藏空中云团。分别观察普通与分块高度图、缓坡、世界接缝和镜头平移。先确认雾面从谷底到山脊连续收薄，再接天气，方便区分采样错位和气候阈值问题。
2. **再接发布链。** 在同一镜头构造少云湿润弱风、少云干燥弱风、湿润强风三组输入。首组应在无主云时出现谷雾，后两组减弱。记录相对湿度、风速、派生密度和雾顶，检查插值、读档首帧、天气更新边界与画质切换。比较相同输入下的模拟结果，确保渲染档位不影响模拟。
3. **恢复完整画面。** 比较谷雾单独显示、仅主云、两者合成的同镜头截图；在城市、国界、不可见区域和远景核对可读性。检查夜侧雾亮度，以及快速缩放时雾边的闪烁。
4. **最后测 GPU 成本。** 在目标桌面和移动或 Web 设备上，同种子、同天气、同路径、同分辨率对比现有高档和新版，记录预热后的完整场景 GPU 平均帧时、P95，以及天气发布时的上传峰值。覆盖无雾、局部雾和大范围浓雾。检查低、中档编译结果及纹理单元预算，避免只靠逐像素分支宣称节省开销。

若完整场景测量确认全分辨率的动态噪声成为瓶颈，再对照试验半宽半高密度 RT。该变体仅在低分辨率计算平滑雾形，最终仍按原分辨率高度裁山脊；把新增写入、采样和合成带宽计入同一测量。

## 验证矩阵与回退

| 风险 | 复现场景 | 判定方法 |
|---|---|---|
| 雾面粘镜头、接缝跳动 | 同一河谷低速平移、快速缩放、横跨东西边界；观察风动半周期和整周期端点 | 固定地物上的雾边连续，缩远后细节平滑消失，静风时无定向漂移 |
| 雾泄出海岸或跨错山脊 | 海岸、高原盆地、相邻双谷、细山脊各取一个固定镜头 | 对照陆地掩码与雾顶差图。若陆上顶点插值把雾带入海面，按现有水陆覆盖在最终合成处抑制 |
| 六边格边、缓坡量化 | 单个有雾格邻接六个无雾格；在缓坡上连续扫动雾顶 | 检查几何插值与编码各自的影响。地形裁边始终使用未扭曲的地表坐标，细噪声只扰动雾面 |
| 装载或切档闪白 | 高→低→高、重载同档、切换不同尺寸世界、跳过多代天气；注入缺字段、错误尺寸和旧代号 | 雾、风和天气同代；没有旧世界残影。对拒绝输入分别断言，不以重试或放宽比较掩盖错帧 |
| 性能退化与平台差异 | 正式场景沿相同相机轨迹比较桌面高档、移动高档和 Web 实际启用变体；记录 API、设备、分辨率、预热与采样帧数 | 同时给出原版和新增成本。分别测稳态与发布瞬间，检查采样器数、着色器编译和持续帧时。无目标机数据的档位标记待验 |

优先扩展现有[天气画质测试](../../Project/project-keynes/tests/rendering/cloud_weather_quality_test.gd)与[天气场 shader 测试](../../Project/project-keynes/tests/world/weather_overlay_field_test.gd)。现有“两张 sampler”等约束代表原路径的既有预算；新增高档变体要单独列出资源清单，低档仍验证原约束。涉及后台发布时补同输入重放与冷载对照，明确验证模拟结果一致、首个天气显示帧正确这两个独立结果。

原型期间保留可选择的旧低雾材质变体，便于同种子 A/B 和目标设备降级。资源绑定失败时回到受支持的天气材质，下一有效发布重新绑定；不能因谷雾缺资源而隐藏全部天气。是否引入专用 RT、是否保留法线受光、各平台最终格式与启用档位，分别由性能对照、截图和设备能力决定。完成记录应包含采用的参数、截图、拒绝输入与回放结果、设备帧时和剩余限制，再同步实际落地状态。
