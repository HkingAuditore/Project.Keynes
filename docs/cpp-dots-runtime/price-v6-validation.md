# Price V6 动态上限：实施与验收

日期：2026-08-30。状态：功能已实现，性能验收进行中。

## 当前价格契约

- 下限沿用 V5：只有 1 个价格子单位（0.0001/完整物资单位）的数值护栏，没有商品经济最低价。
- 商品 `max_price` 改名 `reference_max_price`，原有数值保留。原生旧键和旧资源属性均显式拒绝；内容生成器同步迁移。
- 成本基础上限：`ceil(reference_max_price * max(default_price, cost_anchor) / default_price)`，最大 INT32_MAX。
- 删除上涨锚点平方衰减。上涨以 default/cost 为增量基准，下跌以当前价为基准，原有日涨跌速率限制保留。
- 只有当前上限最后 20% 区域衰减上涨；正向调整被量化吞掉且仍有空间时补一个价格子单位。
- 价格 >=80% 上限、预算支持的未满足需求 >=25%，连续确认 30 个实际游戏日。第 30 日完成确认，第 31 日起具备扩张资格，每日 50bp。
- 已确认后，短缺 10%–25% 暂停扩张；价格 <70% 或短缺 <=10% 退出确认。
- 只有价格 <70% 且短缺 <=10% 同时成立才每日回收 10bp，最低回到成本基础上限。
- 目标上限下降时不强行压低当前价格：禁止进一步上涨，下跌仍走现有速率限制。

这是一套数值稳定护栏，不是政府限价，也不是保证生产者利润的最低售价。确认期内市场价格仍正常变动。

## 有效短缺及性能边界

居民以已分配预算的主订单为基础；后续替代品履约按需求等价量冲销原商品的缺口，避免对同一需求重复统计。
企业投入先受劳动力、气候、自然资源和已分配周转资金约束，再报价；库存不足独立按配方输入边检查，
不能将另一种配套投入的缺失当成所有原料短缺。库存替代品按配方等价量计入可用供给。
维护采用同一所有者共享的临时预算账本。科研在实际交付后，按现有价格排序一次性分配剩余国家预算，
没有重复复制国库资金，也不因统计而实际扣钱。

上限状态是按市场排序的稀疏 `(good, limit, confirmation_days)` 行，无新增市场×商品持久矩阵。
临时企业统计对齐已有 MarketSignal 稀疏列；科研只有每市场一列，因为科研采购仅对应一个商品。
Worker 只输出观察结果；串行汇合后排序并推进状态。合并复用 scratch 容量，热身后不逐行新建分配。
绝大多数远离上限的市场跳过详细短缺归因。贸易预测和 UI 查询复用上限计算，不推进确认状态。

开局错峰结算使用负数历史日，这部分虚拟天数不计入确认期。N=1/3/5 按实际日数重复整数步骤，
不会按调用次数累计，也没有可变步长浮点积分。

## 投资评估的补充优化

极低价格使更多建筑候选通过原有资金门槛，暴露了生活成本的重复计算。单格评估期间，
按消费计划和族群缓存生活成本，发起人筛选也复用同一份结果；每格/每次评估重置，
不跨日缓存。发生饱和的计算仍重做以保留诊断行为。前置资金界限读取与最终筛选相同的
30 日生活储备扣除规则；贷款覆盖规则保持不变。

64 格低价诊断样本中，候选评估数量保持每天约 525 次，投资评估由约 3.6ms 降至 1.8ms，
最终经济状态 hash 与优化前完全一致。该诊断运行不是性能验收样本，最终二进制另做交替对照。

## 性能方法

保留三份隔离 Release：开始修改下限前工作区、已完成下限的 V5、V6。
不使用 Git HEAD 替代用户当时的工作区，不覆盖其既有修改。快照在 `tmp/price_v5/before.zip` 和
`tmp/price_v6/price_v5_before.zip`；DLL 独立封存。

合成测试用正式目录、原生日阶段，无建筑；逐日推进 180 个实际日并彻底排空当日 continuation，
舍弃前 20 日，交替版本顺序重复五次。覆盖规模 8/64/1120、N=1/3/5，以及库存充足、缺货、
最低价格/低余额、接近参考上限、密集活动上限。正式 headless 启动另测 40×28 与 60×40，不能用合成测试冒充正式运行。

验收阈值：日调用 wall avg/p95 回退 <=5%，max <=10%；出现噪声需要十次复测，保留所有结果。
同时报告 price CPU、处理组件数、消费、满足度、守恒和原生容量字节。
`price_ms` 只覆盖 worker 中的价格计算；串行上限状态推进纳入总 wall，不能用 `price_ms` 代表全部新增成本。容量字节不是进程 RSS，
也不代表完整线程局部 scratch 峰值。V5 早期日志误用每次前进五天的测试辅助函数，不能用于验收。

原始输出：`tmp/price_v6/measurements.jsonl` 与对应日志。正式统计和未通过项目在运行结束后补充。
