# 气候/天气模拟数据分析报告

分析对象：`Project.Keynes/tmp/tile_data_record_20260622_143819.csv`

## 数据范围

- 文件大小约 `3.36GB`
- 有效记录：`2,880,000` 行
- 网格数：`6,400` cells
- 时间范围：`450` 个 tick，`tick_idx = 6091 ~ 6540`
- 每个 cell 均有 `450` 条记录
- 注：`phys_sim_day` 存在非单调/重复映射现象，本报告主要以 `tick_idx` 作为时间序列依据。

## 总体结论

当前天气模拟已经具备基础气候带、温度纬向梯度、冰雪纬向分布、降水-土壤湿度联动、天气团块和渐变机制，但还不能完全称为自然气象系统。

主要问题是：

1. 天气空间格局过于稳定，湿区位置变化偏慢，存在明显“固定雨带/固定干区”倾向。
2. 永旱区较多，疑似永雨区也存在，但比例低于永旱区。
3. 天气种类虽然齐全，但强天气、锋面天气、灾害天气出现率过低。
4. 季风、台风、冷锋、暖锋在字段或枚举上有影子，但从数据形态看尚未形成清晰的全球尺度动力学事件。
5. 天气对土壤湿度和植被有影响，但植被响应偏弱，且部分应力字段与天气类型的语义有不一致迹象。

## 天气类型多样性

天气类型枚举全部出现：`CLEAR / RAIN / STORM / BLIZZARD / DROUGHT / FOG / HEATWAVE / MONSOON`。

全量占比：

| 天气 | 占比 |
|---|---:|
| CLEAR | `80.37%` |
| FOG | `9.35%` |
| RAIN | `8.85%` |
| HEATWAVE | `0.81%` |
| MONSOON | `0.24%` |
| BLIZZARD | `0.17%` |
| STORM | `0.17%` |
| DROUGHT | `0.041%` |

判断：

- 天气种类“有”，但生态位不够均衡。
- 普通天气占绝对多数，强天气过少。
- `DROUGHT` 几乎不出现，不足以表现持续干旱事件。
- `STORM / MONSOON / BLIZZARD` 都有，但规模偏小、事件性偏弱。

## 是否符合自然规律

### 符合的部分

纬向温度梯度明显：

- 赤道附近平均温度约 `0.653`
- 高纬/极地平均温度约 `0.057`
- `temp` 与绝对纬度相关系数：`-0.855`

说明温度随纬度升高而降低，这一点非常自然。

降水也有纬向差异：

| 绝对纬度带，0=赤道，9=极地 | 平均降水 | 湿润格比例 |
|---|---:|---:|
| 0 | `0.0209` | `32.5%` |
| 1 | `0.0183` | `29.1%` |
| 2 | `0.0194` | `30.3%` |
| 5 | `0.0081` | `12.5%` |
| 7 | `0.0014` | `1.1%` |
| 9 | `0.0030` | `2.1%` |

冰雪也基本合理：

- `snow_cover` 与温度相关：`-0.461`
- `sea_ice_frac` 与温度相关：`-0.478`
- 高纬海冰均值最高可到 `0.587`

### 不够自然的部分

天气场的日际变化偏慢：

- 湿润区域 tick 间 Jaccard 平均值：`0.980`
- 中位数：`1.0`
- 也就是说，大多数相邻 tick 的降水区域几乎不变。

这说明天气不是持续流动、生成、移动、消亡，而更像是每隔数日刷新一次的准静态场。

天气覆盖面积在 `804 ~ 1077` cells 之间波动，占全图约 `12.6% ~ 16.8%`，总量可变，但位置变化不足。

## 永雨区和永旱区

按 `weather_precip_arr > 0.02` 作为湿润阈值：

- 全记录都湿润的 cell：`2.89%`
- 湿润频率超过 `80%` 的 cell：`5.34%`
- 全记录都干燥的 cell：`27.13%`
- 干燥频率超过 `95%` 的 cell：`28.0%`
- 陆地中干燥频率超过 `95%`：`32.45%`
- 陆地中湿润频率超过 `80%`：`11.53%`

判断：

- 存在明显“永旱区”或准永旱区，比例偏高。
- 存在少量“永雨区”或准永雨区，但规模相对较小。
- 若世界设定不是大量极地/荒漠大陆，这个永旱比例偏高。
- 更大的问题不是“干旱区存在”，而是干湿分布太固定，缺少天气系统迁移带来的随机性和季节性摆动。

## 锋面、冷锋、暖锋、季风、台风

### 锋面迹象

最后一帧邻接边统计：

- 天气类型边界占邻接边：`11.78%`
- 类锋面边界，即温度梯度明显且伴随收敛/降水：`15.29%`
- 湿锋面边界：`5.18%`
- 邻格温度梯度 `p95 = 0.167`，`p99 = 0.293`
- 风切变 `p95 = 1.77`，`p99 = 1.99`

说明数据里确实存在锋面边界/梯度结构。

但问题是：

- 无法从类型上区分冷锋、暖锋。
- 没有清晰的锋面推进、锋后冷空气、锋前暖湿空气的时序证据。
- `STORM / RAIN / BLIZZARD` 只是结果分类，不足以表达锋面成因。

结论：有“锋面形态”，但冷锋/暖锋机制不完整。

### 季风

`MONSOON` 出现，占比 `0.24%`，平均降水 `0.0927`，是所有天气里最高的降水类型之一。

但：

- 占比太低。
- 数据里没有明显的季节性风向反转、陆海热力差主导的雨带推进证据。

结论：季风作为天气类型存在，但尚未形成自然意义上的季风系统。

### 台风

`STORM` 出现，占比 `0.17%`，平均风速 `1.00`，平均降水 `0.0857`，平均不稳定度 `0.581`，这些指标符合强对流/风暴特征。

但：

- `STORM` 团块很小，最后一帧仅 `5` 个 cell，最大连通块 `2`。
- 没有看到旋转结构、暖海面生成、路径移动、登陆衰减等台风特征。

结论：有风暴天气，但还不能称为台风系统。

## 天气对气候和植被的影响

### 对水分/土壤的影响明确

相关性：

- 土壤湿度 vs 降水：`0.716`
- 植被活力 vs 土壤湿度：`0.480`

说明降水能有效进入土壤水分，土壤水分又能影响植被活力。

### 对植被的长期反馈偏弱

- 植被活力中位数为 `0`，但 `p75 = 0.812`，分布高度两极化。
- 植被活力 vs 降水没有直接强相关。
- 植被活力 vs 干旱应力相关仅 `-0.042`。
- `vegetation_growth_pressure` vs 降水为 `-0.088`，方向偏反直觉，需要检查公式含义。

判断：

- 天气通过土壤水分影响植被的链路存在。
- 但植被响应更像被静态生态位/地形/基础湿度主导，天气的动态反馈还不够强。

## 天气生成、分布、变化、消失

过渡指标：

- `weather_transition_alpha_arr`：`p95 = 0`，`p99 = 0.7`
- 每 tick 过渡中 cell 中位数：`253`
- `weather_target_mismatch_count` 中位数：`440`
- `weather_convergence_published`：约一半 tick 发布
- `weather_refresh_convergence`：约一半 tick 刷新

判断：

- 有平滑过渡机制，不是所有天气瞬间硬切。
- 但降水区域 Jaccard 过高，说明天气变化/消失的空间位置不够活跃。
- 部分 tick 之间完全不变，表现为“刷新帧/冻结帧”式变化。

## 主要异常点

1. `RAIN` 平均温度 `0.652`，偏暖，说明雨主要集中在低纬暖区；这本身合理，但中高纬雨/雪事件偏少。
2. `DROUGHT` 平均降水 `0.032`，高于 `HEATWAVE` 的 `0.003`，语义上不太合理。干旱类型出现时不应仍有较高降水。
3. `FOG` 平均云水 `0.392`、水汽 `0.324`，表现过强，可能抢占了本应属于阴天/小雨/湿润天气的生态位。
4. `HEATWAVE` 陆地占比为 `0`，主要在水域出现，这不自然。热浪应主要发生在陆地或陆地边缘，而不是水面。
5. `DROUGHT` 水域占比为 `0` 合理，但陆地占比仅 `0.09%`，不足以形成气候灾害。
6. `wet_jaccard_mean = 0.98` 说明天气移动性不足。

## 研判打分

| 项目 | 评价 |
|---|---|
| 全球尺度温度/冰雪规律 | 好 |
| 降水纬向规律 | 中上 |
| 天气种类完整性 | 中上，类型齐但分布不均 |
| 永雨/永旱控制 | 偏弱，永旱明显 |
| 冷锋/暖锋 | 不完整，有边界无机制 |
| 季风 | 不完整，有类型无系统 |
| 台风 | 不完整，有风暴无台风结构 |
| 天气对土壤/植被影响 | 中等，水分链路明确，植被反馈偏弱 |
| 天气生成/移动/消失自然性 | 偏弱，过于稳定 |

## 建议优先级

1. 降低天气场空间锁定：增加风场平流、锋面推进、随机扰动和季节性雨带摆动。
2. 重标定 `DROUGHT / HEATWAVE / FOG` 分类阈值，避免语义错位。
3. 增强陆地热浪和干旱事件，降低水域热浪。
4. 给 `STORM` 增加海温/水汽/低压涡旋/登陆衰减机制，形成真正台风。
5. 给锋面增加冷暖气团判别：锋前暖湿、锋后降温、锋线收敛降水。
6. 季风应绑定季节、陆海热力差和大尺度风向反转，而不是只作为强降水分类。
7. 增强天气对植被的中长期反馈，尤其是连续干旱、连续湿润、热浪、暴雪对 `vegetation_vitality` 和 `vegetation_growth_pressure` 的影响。
