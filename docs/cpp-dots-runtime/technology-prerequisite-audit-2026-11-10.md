# 科技前置逻辑审计（2026-11-10）

目标是修复资源目击或发展规模替代必要工具、用火、栽培等知识的路径。
唯一作者源仍为 `Project/project-keynes/data/technology/technology_network.json`；
TechnologyCatalog 编译、Country 研究资格、Effect/Modifier 激活和存档所有权均不变。

## 已实现

| 科技 | 补充的不可替代知识 | 行为 |
| --- | --- | --- |
| 铁矿辨识 | 打制石器、自然观察 | 看到铁矿可揭示对象，必须具备取样和矿物比较能力才能研究 |
| 露头煤辨识 | 打制石器、火种控制 | 看到煤可揭示对象，研究需要取样工具及燃烧验证能力 |
| 铜退火 | 火种控制 | 自然铜冷锤和知识机构不能代替受控加热 |
| 铜锡配比与铸造 | 窑烧控制 | 发展规模不能替代熔融、铸造所需的高温控制 |
| 炉火保存 | 火种控制 | 食物储藏与知识机构不能替代已有火种 |
| 独木舟与桨舟 | 打制石器 | 保留沿岸/淡水捕鱼两条路线，均需船体和桨的加工工具 |
| 玉米选育 | 玉米繁育 | 不能从野生采集直接跳到专门选育；实践条件改为现有农业就业/产出信号 |
| 旱作农业 | 雨养小麦田 | 野生谷穗采集不能替代实际雨养种植经验 |

原有硬前置、稳定科技/路线 ID、研究费用、时代定位和建筑/物资绑定保留。
新增硬边同步知识基础、理由与静态连线；炉火保存、青铜铸造按新依赖做时代内最小重排。
普通科技仍没有统一时代锁。内容身份改变，旧存档按既有 exact-catalog 策略拒绝，未新增迁移。

## 扫描覆盖与方法

三个只读 agent 分别检查资源/采掘/冶金 53 项（含 18 项辨识）、工程及相关工业/能源/
交通/计算 189 项、全部农业 75 项和社会 93 项及生命/纺织交叉节点。范围有重叠，数量不能相加。
逐项追踪硬前置、所有可选路线和间接祖先；全量 416 项再做机器闭包与拓扑检查。
徒手观察、野生采集、可替代材料和组织路线不因没有直接工具边而自动判错。

正向证据全满足的闭包仅证明作者知识图可达；不保证实际地图、现金、生产投入或发展节奏。
原始只读报告在 `.codex-temp/tech-audit-resources.md`、`tech-audit-industry.md`、
`tech-audit-life-society.md`，本页记录最终裁定。

## 已确认但尚未修改的设计候选

- **大气式蒸汽机**：某些路线可以绕过全部铜、铁冶金知识。需要表达铜合金/铁等材料能力
  的替代路线，不能简单强加单一炼铁路径。本轮未修改，不能视为已完成修复。
- **微生物学**：分类和实验科学不能保证科学仪器基础；现有“精密仪器”又强制继承远洋导航。
  直接加边会把航海变为微生物学必需知识，需先细化光学/仪器链，本轮未修改。
- 内燃机与热力学、信息论与概率统计：已有实际工具与实践基础，属于理论与实践替代的设计
  取舍，未自动增加硬锁。
