# 地块不良状态图集

`situation_badges.png` 是通过 OpenAI image generation 生成的项目专用 RGBA 位图原件。
生成日期：2026-10-25。实际尺寸 1774×887，透明背景，4×2 布局，无字母/数字/文字。

制作规格：适用于大战略地图近景的八枚统一圆形告警徽章；深色珐琅、黄铜边缘、
高对比象牙色图形，少量红色告警角标。正视平面，粗轮廓，小尺寸可辨识。符号依次为：

1. 面包与麦穗：生活物资短缺。
2. 齿轮与金属锭：工业品短缺。
3. 陶罐与布料：消费品短缺。
4. 不满的人物头像：某个阶层满意度低。
5. 烈日与龟裂土地：正在干旱。
6. 房屋与蓝色洪水：正在洪泛。
7. 闲置人物与铲子：失业率高。
8. 空工作台与凳子：建筑岗位空缺。

由 `scripts/rendering/cell_situation_layer.gd` 冷路径生成八个 AtlasTexture。
每格只计算 alpha 包围盒，保留原图透明通道；运行时不重新生成或上传位图。
导入开启 mipmaps 供地图上 25 px 显示。显示与数据契约见
`docs/cpp-dots-runtime/cell-situation-icons.md`。
