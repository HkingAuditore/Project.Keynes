### 任务 2.2: 牛形状实现

**关键**：宽矮体型、方头、有角

1. **实现 cattle_shape()**：
   - 体型：宽/高 = 0.55（最宽）
   - 头宽：明显大于马
   - **角**：最关键的特征
     ```glsl
     // 实现角的弧形向上伸展
     for (int horn = -1; horn <= 1; horn += 2) {
         // 从头部向上向外伸展 25° 角
     }
     ```

2. **测试**：
   ```bash
   godot --headless -s Project/project-keynes/tests/resource_visual_art_review.gd

   # ✓ 牛有角（最明显的识别特征）
   # ✓ 牛的头比马宽
   ```

3. **角的 shading**：
   ```glsl

   if (uv.y > 0.88 && abs(uv.x) > 0.12) {
       head_color += vec3(0.2, 0.2, 0.2) * 0.3;  // 角的反光
   }
   ```

**验收标准**：
- [ ] 牛明显比马宽（60-70% 更宽）

### 任务 2.3: 绵羊形状实现

**关键**：球形体、蓬松、冲天毛

1. **实现 sheep_shape()**：
   - 关键：使用 Voronoi 造成不规则边缘（蓬松感）
   - 体型：最圆的（宽/高 = 0.65）
   - 冲天毛：头顶卷毛

2. **蓬松感实现**：
   ```glsl
   // Voronoi 式不规则边缘
   vec2 wool_cell = floor(length(vec2(uv.x, uv.y)) * 8.0 + seed);
   float wool_noise = hash(wool_cell) * 0.08 - 0.04;
   body = smoothstep(0.22 + wool_noise, 0.0, ...);  // 边缘不规则
   ```

3. **测试**：
   ```bash
   # 与牛对比
   # ✓ 羊更圆（球形）
   # ✓ 羊的边缘蓬松不规则（vs 牛的方)
   # ✓ 羊有冲天毛（顶部卷毛）
   # ✓ 羊最矮
   godot --headless -s Project/project-keynes/tests/resource_visual_art_review.gd
   ```

**验收标准**：
- [ ] 羊是最圆的动物
- [ ] 羊的边缘有蓬松感（不是光滑的）
- [ ] 羊有明显的冲天毛/卷毛
- [ ] 羊 vs 牛 vs 马 三者一眼可辨

---

### 任务 2.4: 猪形状实现

**关键**：宽矮、鼻子凸出、卷尾

1. **实现 pig_shape()**：
   - 体型：矩形最宽（宽/高 = 0.70）
   - **鼻子**：关键特征，需要明显凸出
     ```glsl
     // 鼻子是单独的球体
     if (uv.y > 0.80) {
         float snout = smoothstep(0.06, 0.0, distance(uv, vec2(0.0, 0.86)));
         snout *= step(0.80, uv.y);  // 只在上部
     }
     ```
   - **卷尾**：从后上方向上卷曲

2. **测试鼻子效果**：
   ```bash
   # 关键：鼻子必须明显凸出，不能太小
   godot Project/project-keynes/project.godot
   
   # 对比：猪 vs 牛
   # ✓ 猪有明显鼻子（牛没有这么明显的鼻子）
   # ✓ 猪的体型更方
   # ✓ 猪有卷尾
   ```

3. **颜色**：
   ```gdscript
   ["bio.pig", 1, 12, "cf9a8a", 0, 0.32, 0.0],  # 粉色或棕色
   ```

**验收标准**：
- [ ] 鼻子明显凸出（可感知的 3D 突出）
- [ ] 鼻子有鼻孔（两个小点）
- [ ] 猪体型最矮最宽
- [ ] 有卷尾（可选但加分）
- [ ] 猪 vs 羊 vs 牛 vs 马 四者都能区分

## 常见问题

### Q: 形状太抽象还是不够抽象？
A: 平衡点是"玩家不需停游戏就能识别"。如果 3 倍 zoom 下仍看不清，说明太抽象；如果显得太像真实照片，说明过度渲染。

### Q: 颜色选择如何决定？
A: 参考 ResourceVisualCatalog 中的现有颜色，每种资源的颜色差异应该 ≥ 30°（HSV 色相差异）或 ≥ 0.2（饱和度差异）。

### Q: 贴花会显得过于复杂吗？
A: 贴花透明度应 < 0.5，且应该是视觉辅助而非主体。主体形状是第一优先级。

### Q: 如何处理形状与现有地形/建筑的遮挡？
A: z-index 规划：
- 地形：z=0
- **资源主体**：z=1
- 资源贴花：z=0.5（在主体下面）
- 树冠/建筑：z=2+

### Q: 能否对不同气候/季节改变形状？
A: 可以，但建议先确保基础形状在所有季节都清晰可辨。季节变体可作为第二阶段优化。
