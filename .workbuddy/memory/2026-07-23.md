### 性能复核与修复（用户追问「考虑过性能吗」后）
- 原方案**未做正式性能分析**。复核后确认：
  - 默认工況（未打开图层）零成本：refresh_active() 在 _active_id=="" 时 early-return，world_runtime_host 的每 tick 调用几乎无开销；GPU 仅一次 LUT 采样 + 混合。
  - **问题1（严重）**：静态图层（海拔/地形/植被/温度/湿度/风/洋流）每 tick 全量重建 _build_lut()，这些场生成后不变，纯浪费；200k 格大地图单日可卡顿数十~数百 ms。仅「资源」需每 tick 刷新。
    → 已修：`refresh_active()` 加 `if _active_spec.get("value","") != "resource": return`，保留资源实时语义。
  - **问题2（微优化）**：_build_lut 原用 for 循环逐字节置 0 填充 LUT buffer，稠密索引下冗余。
    → 已修：改为 `PackedByteArray.fill(0)`（C++ memset）。
  - **问题3（次要，未改）**：每次重建都 `Image.create_from_data` 新 alloc + GPU 重传。资源图层不可避免；alloc 可复用到持久 Image，但非主瓶颈，留待后续。
- 资源图层在大地图仍每 tick 两趟遍历（先求 max 再上色），属「实时储量可视化」必要代价；若未来需优化可改为每 N 日才重算 max。

### 验证状态
- 本地 rebuild 首报 GDScript 解析错误：`map_data_layer_overlay.gd` 中 _va 原为无类型 `var _va = null`，导致 match 内 `var id := _va.get_terrain(i)` 等 4 处 := 无法推断类型。已将 `_va` 显式标注为 `DCViewAdapter.Cell` 修掉。
- 第二处解析错误：`map_layer_menu.gd:94` `var vh := get_viewport().size.y ...`，`get_viewport()` 在此 Godot 构建返回类型未标注（退化为 Variant），三元式退化成 Variant 使 := 推断失败。已将 `vh` 显式标注为 `: float` 修掉。
- 第三处：`map_layer_menu.gd:136` `var disp := spec.get("display",...) ...`，`Dictionary.get()` 返回 Variant，且项目开启「warning-as-error（inferred from Variant）」。已改为 `var disp: String = String(spec.get(...)) if ... else layer_id`。
- 第四处：`map_layer_legend.gd:97` `var cats = _info.get("categories", [])` 用 `=` 接 Variant 退化为 Variant，致 `cats.size()` 返回 Variant、`var n :=` 推断失败。已改为 `var cats: Array = ...`。
- 第五处（第四处的连锁）：`cats` 标成 `Array` 后，`cats is PackedColorArray` 触发「Expression is of type Array so it can't be of type PackedColorArray」。已改为 `var cats: PackedColorArray = ...` 并去掉 `is` 守卫、改用 `.is_empty()`。
- 第六处：`map_layer_legend.gd:112` `var rows := ceil(float(n)/float(cols))`，**此 Godot 构建里 `ceil()` 返回 Variant**（标准 Godot4 应返回 float，此处异常），致 `:=` 推断成 Variant 触发 error。已改为 `var rows: int = int(ceil(...))`。已全量扫描 5 个新建文件，无其他 `ceil/floor/round/...` 配 `:=` 的用法。
- **项目约定**：该 Godot 项目把「从 Variant 推断类型」当编译 error。凡是从 `Dictionary.get()` / `map.get()` / `get_viewport()` 等 Variant 源赋值，**必须显式标注类型**（`var x: T = ...`），不能用 `:=`。已全量扫描新建 5 文件，其余处均已合规（legend 用显式标注、spec_for 返回 -> Dictionary）。
- **Shader 约定（新发现）**：此 Godot 版本**禁止 `void fragment()` / `vertex()` 内裸 `return;`**（早退非法）。早退逻辑必须改写成「先赋默认值 + `if` 条件块包住有效分支」。参照 `shaders/weather_overlay.gdshader` 写法。`data_layer.gdshader` 的 fragment 已按此改造（两处 `return;` → 条件块）。
