| 北极 (0.95-1.00) | -166° (西北) | +158° (东南) |

### 3.2 风场问题诊断

**v1 问题**: 风场在两态间跳变，中纬度方向偏差 ~32°
**v2 变化**: 

| 问题 | 详情 |
|:-----|:-----|
| **风向完全均一化** | 除了南极圈，几乎所有纬度带风向都是 ~+155°-165° (东南风)。这意味着整个球面吹同一方向的风 |
| **丢失风带结构** | 地球应有: 赤道→东风带, 中纬→西风带, 极地→东风带。v1 至少有三带结构 (虽然有偏差)，v2 只剩一带 |
| **SLP 梯度几乎消失** | SLP std 从 0.20 → **0.042**，降了 5 倍。气压场完全平坦，无法驱动地转风 |
| **风速更均匀** | 风速 std 从 0.16 → 0.12，所有纬度风速在 0.46-0.64 窄范围内 |
| **风 X 分量极端偏西** | wind_x 均值从 -0.40 → **-0.87**。几乎所有风的西向分量接近 -1.0 |

### 3.3 根因推测

风场从有纬度变化的多带结构变成全球均一的东南风，可能是以下之一:
- SLP 场的生成逻辑被修改，导致气压梯度消失
- 风场由独立的风带模型驱动改为单一方向的地转风近似
- 或者 SLP 的初始值/边界条件变化导致全场等压

## 九、变化总结

### 改进:
1. **温度梯度增强** — 赤道更暖、两极更冷，梯度比 v1 更锐利 (+0.03)
2. **洋流连续化** — 从 2 态跳变变为连续场，且南半球出现环流结构
3. **海冰季节交替更明显** — 南北极冰量此消彼长幅度增大

### 新问题 / 回归:
1. **风场退化严重** — 从多带风向结构**退化为全球均一的东南风**，丢失了赤道东风带/中纬西风带/极地东风带
2. **SLP 梯度完全消失** — SLP std 从 0.20 **暴跌至 0.042**，气压场变平，无法驱动真实的地转风
3. **wind_x 极端偏西** — 几乎所有 cell 的 wind_x ≈ -0.87 ~ -0.94，风场丧失了空间多样性

### 仍未解决:
1. **天气系统仍然静态** — 81-84% 晴，多数 cell 无变化
2. **季节振幅仍然不足** — 年温差仅 0.23-0.49 归一化单位
3. **中纬度洋流仍然偏弱** — mag < 0.1，无西边界流
