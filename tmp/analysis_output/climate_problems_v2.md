## 问题 #1: 风场退化为全球均一方向 (P0)

### 现象

**所有纬度带的风向都在一个小范围内波动**，失去了地球应有的三带环流结构:

| 纬度带 | 物理位置 | 风向 (deg) | 地球期望 |
|:-------|:---------|:-----------|:---------|
| 0.00 | 南极圈 | 198° (西南偏南) | 东风带 (~90°) |
| 0.05-0.25 | 南半球中纬 | 150-178° (东南偏南) | 西风带 (~270°) |
| 0.30-0.50 | 赤道带 | 156-168° (东南) | 东风带 (~90°) |
| 0.55-0.75 | 北半球中纬 | 162-171° (南偏东) | **西风带** (~270°) |
| 0.80-1.00 | 北极圈 | 136-163° (东南) | 东风带 (~90°) |

**风向跨度**: 从南极 198° 到北极高温带 136°，总跨度仅 **62°**。在地球上，Hadley/Ferrel/Polar 环流的风向跨度约 **180°** (东风→西风→东风交替)。

### 数据证据

```
wind_x 全局均值: -0.865  (v1 为 -0.400)  — 极端偏西, 几乎全是西向分量
wind_x std: 0.236 (v1 为 0.694) — 空间变化率降了 66%
wind_y 全局均值: +0.294 (v1 为 0.278) — 北向分量相对稳定
```

几乎每个 cell 的 wind_x 都在 **-0.71 ~ -0.96** 极窄范围，意味着所有风都是从西边吹来、带轻微南偏北分量。

### 根因推测

风向不再由 WindBelt 模型驱动，或者 SLP 的梯度方向改变了。全局东南偏南风表明可能存在一个简化的「信风处处适用」逻辑，或者 SLP 的南北梯度 (南极高→赤道低→北极高) 驱动了从南半球高压向赤道低压、再向北极高压的单一环流。

### 预期行为

地球风带应该是**三带交替**: 赤道→东风带 (Hadley下沉), 中纬→西风带 (Ferrel), 极地→东风带 (Polar)。风向每跨越一个环流 cell 翻转约 180° (东→西交替)。

## 问题 #2: SLP 气压场梯度不足、范围严重压缩 (P0)

### 现象

全球 SLP 被压缩到一个极窄的、完全为正的范围内:

| 指标 | v1 | v2 | 变化 |
|:-----|:---|:---|:-----|
| SLP 全局范围 | [-0.451, 0.484] | **[-0.011, 0.160]** | 压缩 5.6x |
| SLP std | 0.143 | **0.042** | 降低 3.4x |
| SLP 均值 | 0.026 | **0.063** | 偏移 +0.04 |

虽然 SLP 仍有纬度梯度 (南极 ~0.13 → 南半球中纬 ~0.03 → 北极 ~0.15), 但:
- 整个范围的极差仅 **0.15** 单位 (v1 为 0.94)
- 同一纬度带内的 SLP 变化极小 (delta 0.007-0.12)
- **所有 SLP 值为正**, 失去了低压系统 (v1 有负值区)

### 数据证据

SLP 纬度剖面:
```
南极高纬: 0.126  — 相对高压
南半球中纬 (0.10-0.20): 0.024-0.036  — 低压槽
赤道 (0.40-0.55): 0.024-0.038  — 低压带
北半球中纬 (0.65-0.75): 0.102-0.138  — 高压脊
北极 (0.95-1.00): 0.138-0.149  — 高压
```

虽然有「南半球中纬低压 → 北极高压」的南北梯度存在, 但梯度的**绝对值**太小 (仅 0.12 单位), 既驱动不了有意义的地转风, 也不会产生气旋/反气旋系统。

### 根因推测

SLP 的生成逻辑被简化或重新归一化了, 导致:
- 负压区间消失
- 整体范围被压缩到 [0, 0.16]
- 虽然纬度梯度模式存在, 但强度不足以驱动真实大气环流

## 问题 #3: 天气系统几乎完全静态 (P0)

### 现象

**53.1% 的 cell (1275/2400) 在整个 370 tick 的模拟中从未发生过一次天气变化。**

### 数据证据

```
总 cell 数:           2400
零变化 cell:         1275 (53.1%)
总天气转换次数:       3844 次
平均转换/ cell:       1.60 次 (每 231 tick 一次)
最大转换/ cell:       17 次 (仅 1 个 cell)
```

天气类型多样性:
```
1275 个 cell: 仅 1 种天气类型 (全程不变)
 814 个 cell: 2 种类型
 231 个 cell: 3 种类型
  80 个 cell: 4 种类型
```

全球天气类型占比:
```
type=0 (晴朗):  81-84%
type=1:         5-7%
type=5:         8-11%
type=2,3:       <1% each
```

缺失的天气类型: DROUGHT, HEATWAVE, MONSOON — 从未出现。

### 对比 v1

v1 同样有静态天气问题 (5/14 cell 零变化), 但 v2 的问题规模更大 (53.1% vs ~36%)。type=0 (晴朗) 占比从 75-79% 上升到 81-84%。

### 根因推测

天气的生成和转换逻辑可能依赖风场、SLP 梯度等的大气不稳定性指标。由于 v2 中 SLP 梯度减弱、风场均一化, 天气系统失去了驱动其变化的动力来源。`weather_transition_alpha` 和 `weather_dirty_mask` 的触发条件在均一的大气环境中极少满足。

## 问题 #4: 季节振幅不足 (P1)

### 现象

在不跨越完整年周期的 370 tick 窗口中, 温度振幅测量显示:

| 纬度带 | 陆地振幅 | 水体振幅 | 评估 |
|:-------|:---------|:---------|:-----|
| 南极 (0.0-0.1) | 0.292 | 0.182 | 偏低 |
| 南半球亚热带 (0.2-0.3) | **0.577** (最大) | 0.279 | 可接受 |
| 赤道 (0.4-0.6) | 0.35-0.37 | 0.16 | 预期低 (赤道季节差异小) |
| 北半球中纬 (0.6-0.8) | 0.44-0.49 | 0.22-0.26 | 偏低 |
| 北极 (0.9-1.1) | 0.23-0.30 | 0.13-0.18 | **严重偏低** |

### 问题分析

1. **极地振幅过小**: 极地应为全球季节温差最大区域 (夏季持续日照 vs 冬季极夜)。当前北极振幅仅 0.23-0.30, 南极 0.29。

2. **水体振幅合理, 陆地偏低**: 水:陆振幅比约 1:1.5-2.0, 这符合热惯性差异的预期。但陆地绝对振幅 (最大 0.58) 仍偏低。

3. **窗口局限性**: 370 tick 可能未覆盖完整年周期。v1 的 2083 tick 跨越一个完整年周期, v2 的 370 tick 仅约 18% 周期。实际年振幅可能更大。

4. **`thermal_inertia_land=0.35`** 可能过强, 导致温度响应滞后、振幅压缩。

### 对比 v1

v1 中 2083 tick (完整年周期) 下个别 land cell 的温度 range 从 0.23 (南极) 到 0.55 (中纬)。v2 的 370 tick 窗口下最大振幅 0.58, 考虑到窗口更短, 年振幅可能实际有所改善。

## 问题 #5: 中高纬度洋流过弱, 缺乏西边界流特征 (P1)

### 现象

洋流 magnitude 随纬度飙升到赤道后骤降:

| 纬度带 | 洋流方向 | mag | 评价 |
|:-------|:---------|:----|:-----|
| 南半球热带 (0.05-0.15) | 东向 (+0.15 ~ +0.50) | 0.15-0.50 | 较强 |
| 南半球亚热带 (0.15-0.25) | **西向** (-0.26 ~ -0.39) | 0.26-0.39 | 出现反向流 ✅ |
| 赤道带 (0.30-0.50) | 东向 (+0.03 ~ +0.31) | 0.08-0.31 | 适中 |
| 北半球 (0.50-0.95) | 停滞 (~0) | **< 0.10** | ❌ 几乎静止 |

- 北半球中高纬 (lat > 0.50) 洋流 magnitude 全部 < 0.10, 近乎停滞
- 地球的 Kuroshio/Gulf Stream 等西边界流在地球上最强 (1-2 m/s), 但此处无对应特征
- 南半球「西向回流」的存在是一个有趣的结构, 但在北半球缺失

### 根因推测

可能洋流由风应力驱动, 而 v2 的风场退化为全局均一东南风, 失去了在中纬度驱动强烈西边界流的风应力旋度。

## 问题 #6: 北极冰盖偏弱 (P2)

### 现象

即使在北半球冬季 (tick 1144, 北极处于冰量峰值), 北极冰覆盖率仍偏低:

| Tick | 南极冰率 | 北极冰率 | 推测季节 |
|:-----|:---------|:---------|:---------|
| 959 | **43.5%** | 11.4% | 北半球夏/南半球冬 |
| 1051 | 34.0% | 25.7% | 过渡期 |
| 1144 | **14.4%** | **41.7%** | 北半球冬/南半球夏 |
| 1236 | 24.0% | 29.8% | 过渡期 |
| 1328 | **43.1%** | 21.7% | 北半球夏/南半球冬 |

在北半球冬季 (tick 1144), 北极冰覆盖率仅 41.7%, 而南极在南半球冬季可达 43.5%。北极纬度更高、水体更多 (lat 0.95-1.00 水体仅 7-13%), 应按理有更厚的冰盖。

### 对比 v1

v1 中北极冰最大 ~39%, v2 最大 ~42% → 略有改善, 但仍偏低。地球北极冬季海冰覆盖率可达 70-80%。

## 问题 #7: 降水分布过于均匀 (P2)

### 现象

全球降水集中在极窄的低值范围:

```
降水 mean:  0.034
降水 std:   0.029
降水 p95:   0.075
降水 max:   0.250
```

90% 以上的降水值在 [0.001, 0.075] 之间。几乎没有大范围对流性暴雨 (precip > 0.2 仅出现在极少 cell)。

### 根因

降水生成可能依赖大气不稳定度 (`weather_instability_arr`) 和水汽辐合 (`weather_convergence_arr`)。但在天气几乎静态 + 风场均一的情况下, 缺乏触发深对流上升运动的条件。

### 改进建议序列

1. **先修复 SLP** (P0#2): 恢复 SLP 的生成逻辑, 使其有 [-0.5, +0.5] 量级的范围和有意义的正负压交替, 重建纬度气压梯度
2. **连带观察风场** (P0#1): SLP 修复后, 风带结构应自动恢复。如未恢复, 确认 WindBelt 模型是否仍被调用
3. **天气系统** (P0#3): 在大气动力环境修复后, 天气应有更多变化。如仍静态, 检查 weather_transition 触发阈值
4. **调优参数** (P1-P2): 季节振幅/洋流/冰盖/降水都是二级调参问题, 在大气动力正确后再微调
