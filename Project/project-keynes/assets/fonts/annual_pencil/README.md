# Annual Pencil typography

`PFanHuTuTi_Min.ttf` and `Muyao-Softbrush-2.ttf` are copied from the user-provided Toy Empires reference project. They are used only in Project.Keynes annual-report presentation.

The source project did not include a separate license file beside these fonts. Retain this provenance note and verify distribution rights before a public release.

Font roles:

- `Muyao-Softbrush-2.ttf`: cover title, chapter headings, large numerals and the faint chapter-number watermark.
- `PFanHuTuTi_Min.ttf`: labels, chart captions, running head, footer controls and short supporting copy.

The typefaces stay inside the report's paper presentation. Text remains native Godot UI rather than being baked into images.
