2. 为什么采集者 / 矿工暴富，渔民 / 工匠赤贫（核心）

把"建筑所有权"和"产出定价"叠在一起，机制一目了然。财富流向建筑的所有者，而非劳动量或产量：

阶层拥有/受雇的建筑产品产品单价现金来源性质

因果链 A — 采集者的"食品加工垄断"

communal_hearth（owner = forager，本单元格唯一食品加工厂）每期买入 gathered_plants 7000（@0.36，采集者自产）+ game_meat 3500（@1.48，向猎人买） → 产出 processed_food 12628。
修正：processed_food 不是最优先的 staple_food 必需品——按 survival_household 消费计划，staple_food（优先级0）由 prepared_staples/bread/grain/gathered_plants 满足；processed_food 只满足低优先级的 produce 需求（优先级2），且家庭对其价格弹性=1.0，高价确实会抑制购买。炉灶的高利润来自食品加工增值 + 纵向一体（自产原料又占加工）+ 本格唯一加工厂、无竞争入场，而非"必需品垄断"。
单期毛利 ≈ 778 万（收入 1010 万 − 原料成本 232 万），毛利率被顶到上限 margin=1.0（100%）； 全程累计利润 71.6 亿。39 名采集者靠这一栋建筑坐收 5.78M/人。

因果链 B — 矿工/商人的"铸币矿"

placer_gold_working / surface_silver_working（owner = merchant，employee = miner）产出 gold/silver， 被直接铸成货币（gold/silver 市场库存恒为 0，全程铸币注入 gold 47.4B + silver 29.1B = 76.6B）。 这是一台"印钞机"：矿场永远有钱付工资（矿工累计领薪 456M，仅 2 人分），商人赚差价。
新铸货币先流入矿主与矿工（坎蒂隆效应：拿到新钱者在物价上涨前先享受购买力），是全单元格现金 ×3.02 膨胀的主源之一（另一源为 producer_support_money_issued 亏损补贴铸币 33.1B）。

因果链 C — 渔民的"无约束过剩 + 无加工链"

freshwater_fishing_camp：配置上抽取 freshwater_fish（225/日，extract）、且 supply_price_elasticity=0.5（有弹性）。 但本格（q15,r18）只有 marine_fish、没有 freshwater_fish（resources 全表 30 种里 freshwater_fish 缺席，marine_fish 在列）——资源链接落空，产出不受储量约束，固定产 1800 鱼/日/营。本格其实存在正确的 marine_fish_collector（抽取 marine_fish），却没被用上。 鱼有买家：满足 protein 需求（优先级1），每期被抽走 24,516。但供远大于求（库存 53.1 万）→ 价格砸到 0.107（近地板）。 石器时代没有鱼的下游加工（罐头厂未解锁）是其增值出口缺失的硬伤。 渔民卖鱼现金恰好等于现金支出（cashcov=1.0，收=支=35039），蛋白靠自食 → 现金储蓄恒为 0。 工匠同理：产量小、且要向采集者高价买主食，现金被抽向食物价值链上游。

3. 逐项体检

✅ 守恒 / 数据真实性：合格。 人口、货币、物资审计误差全程恒为 0，记账严谨、无凭空铸造漏洞（铸币与补贴都被显式记录）。
❌ 经济健康度：不健康（长期）。 四大病征：① 全图人口只减不增（births=0）；② 现金总量 ×3.02 通胀无价格锚定；③ 鱼/采集物永久过剩；④ 36 个建筑组因亏损被挂起（loss_suspended）。仅靠实物自给"表面存活"。
⚠ 自然资源平衡：数值"安全"但基本失效。
  • 可再生：timber 自然增长 +16.9 万 ≫ 开采 238；wild_game 再生 +5541 > 猎取 2853 → 储量反而增长，明显开采不足、无稀缺压力。
  • 不可再生：gold_ore 剩余寿命 ~35510 天（约百年），silver/coal/iron 近乎无限，开采量微乎其微。
  • fertile_soil 缓慢退化（−1808，无再生机制）。
  • 根本问题：产出与资源脱钩。 渔场产 1800/日却不消耗任何资源储量；game_meat 产量（~9.6万/期）远大于 wild_game 开采（2853/全程）。资源账目虽平衡，却没有约束产量，于是过剩无上限。
⚠ 市场自我调节：有反馈，但间接且被地板限死（修正）。 价格方向正确（鱼↓0.11、皮草↑3.51、兽肉↑1.48）✅。供给端确有价格反馈，但：① 反馈看的是 sell-through / discard / 库存过剩（经 planned_utilization_q16，按 supply_price_elasticity_q16 缩放），不是"价格低"本身——鱼虽贱却照卖（约 72% 售罄、未大量丢弃），故不触发减产；② 自给型食物生产者有生存地板（survival_food 生产者最低保 1/6 产能，另有 per-group 生存地板），不能减到自家不够吃。因此"便宜的过剩鱼"仍被近满负荷产出，价格→产量的自纠环对低价过剩不敏感。高毛利加工厂 margin 封顶 100% 且无同格新进入者稀释（见下条）。
⚠ 高毛利产业为何无人"加入"：有两道锁（修正）。 ① 业主职业硬绑定：communal_hearth 的 owner_profession_id=forager，build 命令、bootstrap、save-restore 三处都强制业主必须是 forager——渔民根本不能成为新炉灶的业主。出资者（sponsor）虽可是任意异职业富户，但新建炉灶的业主仍被指定为 forager，利润继续归采集者。矿工/商人的铸币矿同理（owner=merchant）。
② 物资阻塞：即便被允许的投资，也要求建材已存在于本地市场库存（_market.stock < quantity 直接判定，不是向商队采购）。但审计全部 252 个建筑发现：没有任何建筑把 construction_components 当作建材，它只被 classical/industrial 建筑（classical_masonry_yard、classical_public_works）使用；石器时代建筑只耗 logs/flint/gathered_plants 或免建材。所以 11869 次被卡几乎都来自后期建筑（需 steel/machinery 等），石器时代本身并非被建材卡死——这削弱了"投资能自动纠偏"的预期。
本单元格 1022 天建筑构成纹丝不动，赤贫渔民既无法自己拥有高毛利建筑、也无法靠投资被重配出去。
⚠ 贸易：全图活跃，但没救本地。 全图派单 26045、到货 25970（99.7%）✅；然而本单元格鱼/采集物的 trade_inbound=trade_outbound=0——过剩根本没被外运套利（可能邻格同样过剩或无利润路线），本地积压无解。
❌ 财富分配：极端且发散。 起点近乎均等，终点最富（商人 6.26M）与最穷（渔民 0.3）人均差约 70 万倍，且不收敛（无劳动力流动、无遗产/税收再分配、加工与铸币租金持续单向累积）。

4. 建议修改方向（按优先级）

  1. 修复渔场资源错配（治渔民赤贫首要）：本格只有 marine_fish、building 却抽 freshwater_fish（落空）。应让该格改用 marine_fish_collector 抽取实际存在的 marine_fish，使有限储量约束鱼产量，从根上遏制 53 万库存的过剩与 0.107 地板价。这是比"加约束"更具体的修法。
  2. 放开高毛利建筑的业主职业绑定 / 稀释垄断租：communal_hearth 的 owner_profession_id=forager 硬绑定是渔民无法进入食品加工的根因。可改为允许异职业富户成为业主，或允许同格新建同类工厂压低 margin=1.0 的封顶利润。
  3. 铸币—通胀锚定：gold/silver 直接铸币 + 亏损补贴铸币共注入 100B+，应设与人口/产出挂钩的货币量锚，或对铸币征税回收，遏制 ×3 通胀与坎蒂隆式财富集中。
  4. 投资物资阻塞：石器时代 construction_components 等本地无库存，使 11869 次投资被卡。需让投资能通过商队采购而非仅"本地现货库存"满足，或放宽 bootstrap 期建筑 prerequisites。
  5. 补石器时代鱼的下游 + 让鱼进食品加工配方：解锁简易熏/腌鱼，并允许 communal_hearth 等以 fish 为输入，给过剩鱼一个增值出口、同时抬升渔民售价。
  6. 修复人口模型：所有 33 个 profession 的 birth_rate_q32 均未设置（默认 0）→ 全图只死不生。若非刻意关闭，应补齐出生率。
