## 1. X12 水系 / 边境（最便宜，7 张）

事实：
- 河流 `_building_has_river`、水体 `_building_is_water`、邻接 `_building_neighbors`（`economy_runtime.h:6264-6266`）。
- 运河 `TradeTopologyStore::canal_edge_mask`（`economy_runtime.h:3246`），由 `refresh_canal_topology` 更新。
- 归属 `_epoch_cell_country`（每 epoch 冻结）。
- 现有 tag 原子表 `_TAG_ATOMS`（生成器 `:3023`）与 `target_tag_dictionary.gd`；没有 river / coastal / border / canal。

方案：

| metric | key | 定义 | 重算时机 |
|---|---|---|---|
| 75 | `cell.geo_flags` | bit0 河畔（has_river），bit1 海岸（任一邻格 is_water），bit2 运河（canal_edge_mask≠0），bit3 边境（任一邻格归属另一国家，不含无主/水） | 领土 hash 或运河 topology generation 变化时；否则复用上次 |
| 76 | `cell.waterway_component_size` | 「运河格 ∪ 河畔格」经 `_building_neighbors` 连通块大小（仅同国格），非水网格 = 0 | 同上 |

- tag：`cell.river` / `cell.coastal` / `cell.canal` / `cell.border`，都是 `metric 75` 的位测试。
  **TargetTag 只有 GTE/LTE/EQ/NEQ**（`target_tag.h:45`），没有位与。两个选择：(a) 新增 `TARGET_TAG_BIT_SET`
  操作符（推荐，一处改动、之后 X13 hazard mask 也能用）；(b) 拆成 4 个 0/1 metric。选 (a)，并把 16 的
  `hazard_today_mask` 改为同一操作符。
- 国家计数：在现有国家 tag 计数槽（`kCountryTagCountSlots`）里追加 border / canal 两槽（X7 的写法）。
- `流域 basin_id` **本期排除**：地图管线里没有流域 id，补它属于 map-generation 域。`watershed` 改用 76（水网连通块）
  的 v1 写法或列为排除，由 C 决定。
- 存档：全派生，不动 schema。两条新列进 `refresh_effect_input_digest` 的按消费者掩码。
- 验收：转移一个格子的归属 → 双方边境 bit 更新、挂 `cell.border` 的诊断 program 因子随之出现/撤销；建一条运河 → 76 变大；
  领土与运河都不变的 30 天 75/76 重算次数 = 0（计数器 `geo_flags_rebuilds`）。

## 2. X14 民心（5 张）

事实：
- `CountryClassOpinionSnapshot`（`economy_runtime.h:1225`）每次提交双缓冲发布，含每国每阶层 `satisfaction_q16` 与
  人口加权值。理念支持度已经通过 `ideology_opinion_bridge.h` 读同一份。
- 阶层表 `_political_class_ids`（`economy_runtime_carrying.cpp:384`）。

方案：
- 不要走格 metric。做成**国家级 metric**，与 47-49 同形（`count_q16` 编码的国家标量）：
  - 77 `country.class_satisfaction_q16[class]`：按阶层参数化。现有 metric 是标量，没有参数；做法：生成器给每个
    阶层展开一个 metric id（阶层数小且固定；`_political_class_ids.size()` 在 configure 时已知）。
    如果阶层数 > 8，改为参数化 metric（`metric_param` 进条件）——先测阶层数再定，测量结果写进汇报。
  - 78 `country.weighted_satisfaction_q16`：按影响力加权的全体阶层。
- 取数在 `capture_country_epoch` 里从**上一份已提交快照**拷（与理念点累积同源），不读正在写的缓冲。
- 性能门：6400 格 class-opinion 中位数 < 1 ms（skill 门槛）——本项只拷 country×class 个数，不应靠近。
- 验收：注入某阶层满意度变化 → 条件卡（诊断 program `v9_class_gate`）开/关；不声明 77/78 的卡 refresh visits = 0。

  - 79 `country.completed_tech_count`：popcount(科技位)。
  - 80-83 `country.completed_tech_count.<domain>`：按领域 popcount。要求 Country 在 configure 时把
    `_technology_domains` 传给 Economy（只传一次，静态目录），Economy 按领域建 4 个掩码，popcount(bits & mask)。
    领域数若不是 4，按实际数展开并报告。

  走 02 §4.7 的「理念侧标量」：在 activation signature 里混入 `unlocked_era`，并把它作为条件输入一并做（见 §5）。
- 新纪元 / 科技完成事件：归 15 的 X4 事件流（`ERA_CHANGED` 已在 15 D4；加 `TECH_COMPLETED{value=domain}`，
  由科技位 diff 产生）。本文只做计数 metric。
- 验收：给某国打一项科技（测试入口）→ 79 与对应领域 +1；科技不变的日子重算 0 次。
