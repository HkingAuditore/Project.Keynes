## 五、关键问题汇总

| # | 问题 | 严重度 | 数据证据 |
|:--|:-----|:-------|:---------|
| **1** | **植被全局衰退** | **P0** | 所有陆地 cell 活力持续下降 (11-19%/700tick), 生长压力全为负值 |
| **2** | **水体植被为占位值** | P1 | vitality 恒为 0.700, 所有胁迫/压力为 0 — 非真实模拟 |
| **3** | **干旱胁迫永不触发** | P1 | 全球 drought_stress ≈ 0, 即使土壤水分差异 100 倍 |
| **4** | **热胁迫排除赤道** | P2 | 赤道温度最高 (0.84) 却无热胁迫, 南半球中纬 (0.26) 却有 |
| **5** | **寒胁迫反常分布** | P2 | 北极寒胁迫 (0.05) < 北中纬 (0.50-0.60), 按理相反 |
| **6** | **土壤水分过度压缩** | P2 | 全球范围 0.003-0.29, 实际应有更大动态范围 |
| **7** | **水分循环过于保守** | P2 | moisture/base_moisture 偏差 < 10%, 缺乏干湿周期 |
| **8** | **赤道水体最干** | P2 | 赤道水体 moisture=0.45, 低于高纬水体 0.72-0.76 |

### 根因推测

1. **植被全局衰退**: 生长压力公式中, 正面的生长力 (温度、光照、水分) 不足以超过负面压力 (基础代谢消耗、胁迫惩罚)。可能需要调整 `vegetation_regen_score` 与 `vegetation_growth_pressure` 的平衡关系。

2. **胁迫逻辑不完整**: 热胁迫排除了赤道（可能是「热带适应」逻辑过强）、寒胁迫排除了极地（可能是「耐寒」阈值过高）、干胁迫几乎不触发。

3. **水分系统过于保守**: moisture 被 base_moisture 锚定, 偏差极小。缺乏短期天气事件带来的水分波动。soil_moisture 的范围需要放大。
