📊 核心方案对比
================================================================================

当前情况：
  小麦、玉米、水稻、土豆 → 看起来都一样 ❌
  马、牛、羊、猪 → 看起来都一样 ❌
  整体显得"平坦"且难以辨认 ❌

优化后：
  小麦 = 直立、细穗、尖头、金黄 ✅
  玉米 = 直立、粗穗、圆头、橙黄、有须根 ✅
  水稻 = 下垂、细穗、米白、最高 ✅
  土豆 = 矮胖、球形叶、深绿 ✅

  马 = 细长、长颈、竖耳、棕色 ✅
  牛 = 宽矮、有角、黑/花纹 ✅
  羊 = 球形、蓬松、冠天毛、白/灰 ✅
  猪 = 矩形、鼻子凸、粉/黑色 ✅

  一眼可辨识度：↑80% ✅
  视觉质感：↑ ✅

💡 关键洞察
================================================================================

1. 形状区分是首要目标
   - 小麦的关键：尖头 + 细穗
   - 玉米的关键：圆头 + 粗穗 + 须根
   - 水稻的关键：弯垂弧度

2. 动物的标志特征
   - 马：长颈 + 竖耳
   - 牛：有角（最重要！）
   - 羊：球形 + 蓬松 + 冠天毛
   - 猪：鼻子突出

3. 不需要纹理图集
   - 完全程序化 SDF
   - 零额外采样
   - 保持性能

4. 可渐进优化
   - Phase 1 可单独做，效果即时
   - Phase 2 在 Phase 1 基础上改进
   - Phase 3 锦上添花
   - 任何时刻都可回滚
