# 科技工作区动效

科技工作区沿用纸张、铜金、墨线与印章的图谱语言。素材复用
`assets/ui/technology_tree_v1` 内既有 ImageGen 位图；研究清单也使用同一纸卡。

## 交互反馈

- 可研究、科技树和总览切页：0.52 秒从上至下展露纸页，扫描前缘带铜金反光。
- 切时代：重播纸页展露；每日快照更新不重播。
- 悬停：角标在 0.12 秒内显现。
- 选中：铜金角框从外侧收拢，一次扩散描边；相关已知路径持续显示有方向的金线。
- 研究中：进度实际端点带柔光，卡片边缘光点沿边运动。清单只强调各领域队首。
- 新发现 / 加入队列：短促描边与少量金粉。
- 研究完成：既有完成印章缩落、扩散圆环和金粉。待生效变成已掌握时不重复庆祝。
- 详情切换：只在选择变化时淡入，不随每日数值变化闪烁。

## 绘制边界

`TechnologyEffectsLayer` 只接收视图已筛选的节点矩形、状态、领域色、实际进度
和已知关联路径。它不查询科技目录、国家 facade 或模拟数据，也不提交研究命令。
未知科技仍保持原有隐名规则，流光不显示未知路径。

每个研究清单或树状画布只增加一个 `MOUSE_FILTER_IGNORE` 子画布。文字与纸卡
仍按状态、悬停、选择、滚动事件重绘。持续特效独立以 30Hz 重绘；最多 18 条
流动路径 / 研究高亮、12 个并发事件，曲线路径只在几何或选择变化时缓存。
树状画布的平移偏移与清单可视滚动区域同步到特效层，裁剪沿用原视图边界。

首次快照只建立基线；隐藏时丢弃事件并停止处理，重新打开不补播后台事件。
`GameSettings.reduce_motion` 更新后立即停掉持续动画并保留静态选中角框。
纸页 shader 只在切页短暂使用，结束后还原原画布，避免持续扫描影响阅读。

## 验证

- `tests/technology_workspace_smoke_test.gd`：既有清单、迷雾、布局、交互、刷新耗时。
- `tests/technology_motion_qa.gd`：首次载入、完成去重、输入穿透、平移对齐、隐藏
  停止、减少动态效果和独立重绘。使用真实科技目录的确定性展示夹具。
- 同一 QA 带渲染运行并传入 `-- --capture`：1280×720 / 1920×1080 的三视图
  PNG 与 54 帧动效序列，输出至 `tmp/technology_motion_qa/`。

运行时只改表现层；研究状态、成本、前置、解锁、队列命令与存档语义保持原契约。
