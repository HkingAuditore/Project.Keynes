## 诊断：植被 vitality 收敛到 0.69~0.71

**现象**（`tmp/tile_data_record_20260702_102543.csv`，tick 3991，60×40 地图，6400 cell/tick）：
有植被的格子 vitality 几乎全部落在 0.69~0.71 极窄区间，无论植被类型/环境差异。veg=0/水格=0.0 合理；veg=22/23/26（特殊类型）也=0。

**根因（代码层）**：三机制叠加形成"棘轮"效应，把 vitality 钳在 0.70 附近。
1. **初始值锚定**：`hex_cell.gd:630` 所有植被格初始 vitality = 0.7。
2. **不对称阻尼（核心）**：`world_ext_climate.cpp:5773-5789` 更新公式 `vit += (target-vit)*rate*scale`，`rate=vitality_change_rate=0.010`，`scale=weather_vegetation_dynamics_stride=5`。**上升全速，下降乘 `compat_harshness=0.35`**（下降仅 35% 速度），且 vit<0.40 时还有二次阻尼（`vegetation_low_vitality_damping_threshold=0.40`，最低再乘到 25%）。→ 高 compat 格快速冲到 target，低 compat 格极慢下降。
3. **演替重置钳位**：升级演替（vit>0.75 持续90天）把值重置到 `(vit+0.7)*0.5≈0.725`（上限钳位）；退化演替门槛 vit<0.25 持续45天 难以达到（下限保护）。`map_generator.gd:13897/13913`。

**target 公式**：`clamp01(compat + water_pressure[-0.12,0.12] - weather_stress - stress_max*0.25 + regen*0.10)`。compat 是 2D 高斯主导项（`vegdyn_compat_of`，`world_ext_climate.cpp:4269`），晴天 weather_stress=0。

**修复方向**（参数在 `climate_profile.gd:599-621`，earth_like.tres 不覆盖任何 vitality 参数）：
- 提高 `compat_harshness` 0.35 → 0.7~1.0（让下降更快，最直接）
- 或降低 `vegetation_low_vitality_damping_threshold`
- 或提高 `vitality_change_rate`
- 或让初始值更分散 / 不锚定 0.7
