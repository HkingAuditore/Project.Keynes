结论摘要

0. 经济运行体现出的特点

这是一套守恒完整、但分配和就业脆弱的早期地块经济：全局人口/货币/物资审计误差为 0，说明不是账本损坏；选中 cell 内，商人库存/现金承接交易，居民通过建筑 owner/employee 岗位获得收入，失业 cohort 退化为只消费 staple_food 的生存计划。

1. 健康性判断

当前不是健康稳态，而是模拟上自洽的贫困化/失业化路径：消费仍在从居民向商人转移，但建筑岗位、工资或利润没有稳定把购买力回流给居民。

2. 失业根因

源码中就业目标由 count × slots × planned_utilization_q16 决定；owner 岗在建筑不可用或 utilization 为 0 时清零。因而大量失业不是“闲置字段”，而是建筑容量/利用率/输入盈利/岗位容量不能吸收人口后，C++ A1 机制把未被雇佣者迁入 unemployed cohort。

3-6. 设计改进方向

优先处理三类问题：① 石器时代建筑岗位与基础食物链是否足以吸收初始人口；② 商人采购/零售价差是否造成早期现金单向蓄水；③ survival 与 plan_unemployed 的基础消费是否过宽/过硬，导致早期社会在未解锁建筑时追逐住房、卫生、医疗等不可得品。

模型机制对照

就业：planned_role_demand = count × employee slots × planned_utilization_q16；planned_owner_demand 在 utilization > 0 时保留 full owner，否则为 0。未被任何建筑岗位吸收的非商人人口会迁移到 unemployed signature。
消费：plan_unemployed 只消费 staple_food，候选为 bread, gathered_plants, grain, prepared_staples；survival_household 同时覆盖食物、蛋白、蔬果、衣物、住房、家用品、卫生、医疗、能源。
市场：household 支出直接进入本地 merchant；建筑生产输入从 merchant 库存购买，输出由 merchant 预算采购。价格压力同时包含家庭需求、企业需求、目标库存、短缺、成本锚和闲置回归。

建议修正优先级

P0：先稳住石器时代闭环

  • 验证 gathered_plants/game_meat/processed_food/grain 是否足以覆盖 plan_unemployed 与 survival_household 的 staple/protein/produce。
  • 给石器时代基础建筑设计最低就业吸纳与最低现金回流；否则人口一旦转为失业者，只剩消费泄漏。
  • 对不可得高阶 survival need 在早期时代降权或移出 survival，避免“石器时代追求现代家庭篮子”。

P1：修商人现金蓄水

  • 给本地 merchant 引入最低采购义务/库存目标约束，减少只收零售款、不足额采购的早期蓄水。
  • 检查 merchant buy factor 与 price cap，确保基础食品短缺时生产者仍能获得收入信号。
  • 将采购缺口、discarded output、price cap hits 暴露到 recorder，便于下一轮定位。

P1：建筑 profile 复核

  • 对本报告中的 active building 表逐项检查投入产出比、资源 capacity、owner slots 和 wage_policy。
  • 石器采集/狩猎/火塘链应尽量少依赖现金购买中间品，否则早期市场尚未成形时容易锁死。
  • 对 planned_utilization_q16 的盈利反馈加平滑和下限，防止一次短缺后岗位雪崩。

P2：下一轮验证

  • 保留当前 CSV 作为 baseline；修改 profile 或公式后重复 recorder。
  • 要求审计误差继续为 0，并比较 N=5 默认周期下 unemployment、sat_min、merchant_funds 三条曲线。
  • 如怀疑 frozen-cycle 放大震荡，再与 N=1 reference 对照，不能只看守恒。
