## 物价 runaway 诊断（cell 622 / v16 录数）
- 用户问：价格为何涨到几万、且高价不触发生产投资、市场调控为何失效。
- 实测：价格不是"几万"，而是直接钉死在 `PRICE_NUMERIC_GUARD_MAX = INT32_MAX = 2,147,483,647`（约 21 亿）。
- 根因1（无上限）：catalog 的 `good_max_price`/`good_min_price` 只在加载时做合法性校验（economy_runtime.cpp:2245），更新循环里从没被当钳制用。更新里唯一硬钳制是 INT32_MAX。用户"想要无上下限"其实已是现状（最坏形式）。
- 根因2（正反馈）：`cost_floor_price`（:4737-4740 + :12241-12248）在"有生产锚且任意缺货"时把价格强行顶到锚价；锚价用**当前实时输入价**算，稀缺输入→高锚→输出被顶高→级联。logs 轨迹 ep400≈8k→ep600≈880万→ep800=INT32_MAX，之后 1100+ 期钉死。
- 为何下不来：向下力只有 (a) cost 拉（需供给>0，否则 confidence=0 失效）(b) 闲置回归（需 dem==0&sup==0&stock==0 同时成立）。钉死货残留 business_demand 信号+库存 → 两力皆失效 → 死锁。
- 为何高价不投资（市场调控"失效"真相）：投资确实把价算进利润，但同一场通胀抬高了门槛：建造成本 `construction_cost=Σ qty×市价` 用通胀后价计价→赞助人资本不够→`SPONSOR_CAPITAL`(最新全局10)；建造材料须已在库 `materials_ready`→`MATERIALS`(121)；输入链可得性→`INPUT_CHAIN`；利润率被抬高的输入成本挤→`TARGET_MARGIN`；资源→`RESOURCE`(300)；资本评审每10天一次；无对应建筑类型则连候选都不生成（永久 INT32_MAX）。本质是死亡螺旋/死锁，非价格→生产链路断开。
- 建议修复（未实施，待用户确认）：A 把 good_max_price 真正用于更新末尾钳制（止 runaway）；B 锚价改配方基准参考成本/限量顶价打断正反馈；C construction_cost 用价钳到 good_max_price 免疫尖峰；D/E 高离谱价均值回归排水 + 零供给也保底 cost 下拉。
