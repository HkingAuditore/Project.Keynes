# 产业链简并与时代演进审计

> 审计日期：2026-07-14  
> 文档性质：下文第 1-7 节保留为重构前问题基线，不再代表当前目录。  
> 重构前快照：136 goods、182 buildings、30 resources、15 needs、5 consumption plans  
> 目标：减少横向重复物资和并行配方，让新科技优先带来新生产方式、替代品与互补投入，并使产业复杂度随时代逐步上升。

## 0. 2026-07-14 实施结果

- 当前目录为 120 goods、261 production-method buildings、31 resources、33 professions、18 needs、8 consumption plans；新增建筑复用既有 goods，表达跨时代生产法而非新增中间品。
- 已退休 11 个无决策中间 goods，并加入 `prepared_staples`、`fine_clothing`、`fine_furniture`；
  `flour`、`wood_pulp`、`pig_iron`、纱线、`textile`、切石/精砌石不再形成单下游转手层。
- 主粮和 cloth 在每个累计时代均有零库存可启动方式；逐时代固定点闭包审计为 100%。硫/炸药与
  石油/机械闭环已由早期采集方式、堆肥和早期油井拆开。
- `tech.legacy_modern_economy` 已删除；现代建筑迁入现有 steam/electrification/electrochemistry/
  radio/advanced_metallurgy/digital/networked 等科技标签。
- 显式输入候选 CSR 已进入 `BuildingProfile -> EconomyCatalog -> NativeEconomyRuntime` 原路径，

- 金银采集建筑均由 merchant 拥有；后期档允许雇员和工具，但仍严格要求唯一金/银产出与对应矿藏。
- 32 职业已映射为八套结构不同的消费原型；每个 need 最多四个 variants，新增工作装备与身份消费。
- 17 个 need 与八套原型已全部中文化，并改为九项基础需求加基础/舒适/奢侈三档缩放。主食、
  耐用品、能源等使用不同的现实频率基准和财富弹性，不再把三类食物及全部非食物套用同一数量。
  医疗补入药材，家庭能源补入原木/煤/燃气/精炼燃料，工作装备覆盖石器到精密工具完整序列。
- 居民需求移除铁路设备、远洋船舶和科学仪器等资本品；铁路与船舶在基础设施/服务经济接入前

  同时计入主食与蔬果。Inspector 以 native good 聚合量显示唯一商品行，并附加全部中文用途。
- 鱼罐头已从探索时代后移：启蒙时代 `canning_workshop` 首发，蒸汽时代 `canned_fish_plant` 工业化。
- 工具序列为打制石器（品质 1）→ 青铜工具（2）→ 古典铁/钢通用金属工具（3）→ 启蒙精密工具（4）。高品质向下兼容，探索以后禁止打制石器，信息/AI 只接受精密工具。
- 生成器已将早期单点生产源强制分类为“持续升级”或“指定时代收敛”；未分类内容会令 codegen
  失败。马匹只保留青铜时代的繁育营地与封建养马场，不再生成科学化、先进化或数字化升级。
  当前时代新增建筑数为 `12 / 25 / 17 / 23 / 14 / 12 / 55 / 36 / 16 / 19 / 30`，不再以人为
  最低数量门槛填充低份额生产方式。
- 纸草、羊皮纸及对应加工建筑已删除，抄写室直接消费采集植物或生皮；食用油已接入加工食品，
  避免形成只有自身升级建筑、没有规模化下游的小产业。
- 建筑经营结构已纳入全目录审计：行会化/科学化商业农场为地主—佃农，机械化/电气化农场仍由地主
  持有，但转为雇佣农业工人和经理；机械化是生产方式变化，不等于土地所有权自动工业资本化。高级
  工坊必须配置师徒与工具；成熟工厂按时代扩大并分化产业工人、专门人员、技术员、
  工程师、研究员和经理。蒸汽工厂要求维护工具，电气以后要求电力及适用的工业机械，不再让计算机
  厂与塑料厂共享同一岗位模板。
- `gen_modern_economy_content.ps1 -Check` 与 `audit_economy_content.ps1` 已通过。当前权威设计见
  `docs/cpp-dots-runtime/cross-era-industry-tech-tree.md` 和 `cross-era-economy-content.md`。

## 1. 结论

当前目录不是“物资太多”这么简单，而是三种粒度同时存在：

1. 食物、纺织等早期生活资料按具体品种拆得很细。
2. `industrial_chemicals`、`industrial_machinery`、`construction_components`、`processed_food` 等后期物资又高度聚合。
3. 60 座建筑使用 `tech.legacy_modern_economy`，把蒸汽、电气、原子和信息时代的生产方式压进同一个时代。

因此目录横向不均、纵向也不连续。推荐的总方向是：

- **保留上游地理差异**：小麦、稻米、玉米、马铃薯可以保留，因为产地、土地条件和贸易价值不同。
- **合并下游用途相同的成品**：米食、玉米食、薯食合并为一种“熟制主食”；原料和工艺仍可不同。
- **把行业分类和配方角色彻底分开**：行业展示继续使用 `industry.*`；`substitution_category_ids` 允许一个 good 同时加入多个配方角色组，建筑的每个输入槽只选择一个角色。`category_id` 仅保留为主角色兼容字段。
- **用升级族表达生产方式演进**：旧设施继续存在，新科技解锁同一产出的高效率方法，并逐步增加工具、能源、化学品等互补投入。
- **先消除不可启动闭环，再做内容扩充**：当前硫/炸药和石油/机械两组反馈链在零库存下不能启动。
- **奢侈品不必先新增很多 goods**：现有 `fur`、`spices`、`jewelry`、`beverages` 已足以形成跨时代的四种奢侈品替代，只缺需求接线和早期生产方式。

建议先做内容层重排，不新建平行经济系统。只有当确实需要“同一建筑可切换多套配方”时，再单独评审生产方式模型。

## 2. 现有机制与审计口径

### 2.1 当前权威路径

- `BuildingProfile` 同时表示建筑和单一生产配方；不存在独立 recipe 资源。
- `EconomyCatalog` 把 goods、buildings、professions 和 resources 编译为稳定索引及 CSR 列。
- `NativeEconomyRuntime` 是建筑、库存、生产、就业和结算的可变权威；GDScript 只编译内容并提交粗粒度命令。
- 建筑、物资和职业的全部 `tech.*` 标签是 **AND 条件**。审计时代取一个条目所有科技标签中的最晚时代。
- 同一升级族中，只允许新建当前科技可用的最高 tier；旧建筑不会自动升级，也会继续生产。
- 生产输入的多个槽位是互补品；同一槽位的候选 goods 才是替代品。

### 2.2 替代机制的真实使用情况

替代类目现在采用多重配方角色：例如蒸汽机同时属于通用、工业和农业动力角色，钢材同时属于铁系材料和结构金属，亚麻纤维同时属于通用纺织、天然纤维、行会纤维和碎布造纸原料。建筑槽位选择具体角色，因而农业机械不会仅因“都是动力”而接受电动机，行会织造也不会接受尚未出现的合成纤维。

`production_efficiency_q16` 仍是 good 级基础效率；当效率取决于具体配方时，继续使用显式候选 CSR。例如面包坊、酿酒、合成织造和不同机械的动力输入保留各自候选及效率，不用宽泛类目抹平工艺差异。

适合立即使用 category 的场景：

- `tools`：石器、青铜工具、钢制工具、精密工具。
- `writing_media`：纸草、羊皮纸、纸张，并用质量门槛区分抄写与印刷。
- `containers`：陶器、玻璃容器、工业包装，并用质量门槛控制保存工艺。
- `starchy_staple`：混合谷物、小麦、稻米、玉米、马铃薯，供熟制主食配方使用。
- `cereal_grain` / `baking_grain`：只包含真正的谷物；马铃薯不会因此进入面包或酿造配方。

不适合直接用单一 category 的场景：

- 同一种原料在不同工艺中的相对效率不同。
- 一个 good 同时需要属于两个功能组，例如玉米既可磨粉也可直接烹饪。
- 配方需要在若干完整 BOM 之间选择，而不是在一个输入槽内换料。

这些场景应先用多个 BuildingProfile/升级族表达；若数量仍失控，再扩展现有 InputCandidate CSR 的内容入口，而不是另写一套生产运行时。

复杂度的平均趋势大体上升，但时代分配失真。关键不是要求每个时代新增相同数量，而是：中期不能空洞，后期应更多地深化旧链，而不是一次性抛出 60 座互相依赖的现代工厂。

另外，98/136 goods 只有一个生产者。单生产者不必然有问题，但盐、纸、工业化学品、工业机械等基础中间品既是单生产者，又与时代或反馈环冲突，会形成系统性单点故障。

升级族目前只有 20 个、覆盖 42/182 座建筑。只有 `subsistence_food` 和 `household_cloth` 达到四档；绝大多数现代建筑没有前身或后继。这正是“科技增加商品，却没有改变旧生产方式”的根因。

## 4. P0：会阻断生产的结构问题

### 4.1 纸张与包装

当前路径：

```text
古典/探索：papyrus / parchment
探索：packaging_plant、printed_materials_plant 需要 paper
信息：logs + industrial_chemicals -> wood_pulp -> paper
```

`paper` 自身标记为古典时代，但唯一生产建筑在信息时代；木浆又依赖信息时代工业化学品。由此直接阻断包装和印刷，并级联阻断七座探索/蒸汽食品工厂。

建议：

1. 新增或改造一个 `rag_paper_workshop`，在 `tech.writing` 或 `tech.printing_press` 使用植物纤维/旧布生产低效率 paper。
2. 将 `wood_pulp_plant -> paper_plant` 定为蒸汽时代的工业升级族。
3. 将纸草、羊皮纸、纸归入 `writing_media`，抄写可接受低质量媒介，印刷要求较高质量。
4. 食品工厂不再一律精确要求 paper packaging；需要保存容器的配方改用 `containers`，普通面包不要求包装。

### 4.2 盐

`salt` 标记石器时代，唯一生产者 `salt_collector` 却在信息时代，直接阻断探索时代的鱼类保存，也参与阻断工业化学品。

建议把盐业拆成同一升级族：早期盐田/浅层盐场不需要工业投入，现代盐矿才使用机械和电力。无需新增新的 salt good。

### 4.3 机械化农业

蒸汽时代的 `mechanized_farm` 同时要求 `fertilizer` 和 `agricultural_machinery`，两者唯一生产者都在信息时代；`ranching_station` 同样依赖农业机械。

建议：

- 蒸汽档机械农场只要求蒸汽机械/钢制工具，表达收割、脱粒和泵送机械化。
- 电气档集约农场再加入化肥和电力。
- `agricultural_machinery` 的早期生产方式使用 steel + steam_engines/machine_parts；后期方式再使用 engines、electric motors 和工业机械。
- 肥料应有早期有机/矿物方法与电气时代合成氮方法，不能只有天然气路线。

### 4.4 零库存反馈闭环

逐时代固定点审计假定自然资源存在、市场初始 goods 库存为零。结果显示 58 座建筑不能只依靠此前已可生产的物资启动。除了上述时代倒挂，还存在两组真正需要“种子库存”的现代闭环：

```text
sulfur -> explosives -> sulfur_collector -> sulfur

crude_oil -> lubricants -> machine_parts -> industrial_machinery
    -> oil_collector -> crude_oil
```

第二组还把 natural_gas、petrochemicals、plastics、wire、engines、fertilizer 等大量下游一并锁死。

建议遵守一条硬规则：**任何新增时代的基础资源采集方式，都必须存在一个只依赖此前时代可得工具/能源的启动配方；炸药、自动化和高端机械只能作为升级输入。**

具体修复：

- 早期 sulfur 采集不使用 explosives；爆破硫矿作为后期升级。
- 早期油井使用 steel + precision_tools/steam_engines；电气化油田再使用 industrial_machinery + electricity。
- 蒸汽时代通过早期油井启动矿物润滑剂；machine_parts 直接使用独立的 `lubricants`，不再把食用油视作全局或配方替代品。
- 其他现代矿场采用“基础矿井 -> 爆破矿井 -> 电气化矿井”升级族，不能把 explosives 和 electricity 同时设为第一座采集建筑的硬前提。

当前 `economy_test_bootstrap.gd` 只验证石器中期、初始库存为零，没有逐时代授予科技并验证闭包，因此这些问题没有被现有测试覆盖。

## 5. 按产业链的简并建议

### 5.1 主食与食品

当前问题：

- `grain` 与 `wheat_grain` 并存；小麦从青铜时代产出，到信息时代 `grain_plant` 才有消费者。
- `corn_food`、`rice_food`、`potato_food` 是用途相同的终端物资，但各自复制早期/蒸汽两套建筑。
- `corn_food` 甚至不在 `staple_food` 的家庭需求变体中，只作为信息时代 `processed_food_plant` 的一个互补输入。
- `processed_food_plant` 把蔬菜、猎物肉、乳品、玉米食、香料、盐和包装七项全部设为互补品，相当于每单位加工食品都必须同时含有七种原料。
- `beverages_plant` 使用 processed_food + packaging，工艺语义不成立。

推荐目标：

| 层级 | 保留/合并 |
|---|---|
| 地理原料 | 保留 wheat、rice、corn、potatoes；它们表达土地和贸易差异 |
| 通用谷物 | 退休 `grain_plant`；`grain` 要么作为混合谷物保留并明确来源，要么在迁移时退休，二选一 |
| 淀粉主粮 | 不保留 flour 等纯转手中间品；`starchy_staple` 将马铃薯和地域谷物接入统一熟制主食配方 |
| 熟制主食 | 将 corn_food、rice_food、potato_food 合并为一个 `prepared_staples`；不同厨房/工厂可以输出同一 good |
| 面包 | 保留 bread；面包坊直接接受小麦、混合谷物和玉米等合理候选，不经过面粉转手层 |
| 综合加工食品 | 保留一个泛化终端 good，但把七项强制互补拆成若干完整生产方法，或减少为基础食材 + containers |
| 饮料 | 早期酿造与后期瓶装形成升级族；输入应是谷物/农产品/香料及容器，而不是 processed_food |
| 鱼类保存 | 将 canned_fish 改为更宽的 preserved_fish，接受盐 + 合适容器 |

这样既保留“哪里产稻米/小麦/玉米”的地理选择，又不会为每种主粮复制一个消费者看不出差别的终端 good。

### 5.2 奢侈品

当前 `luxury` 只有 jewelry 和 beverages 两个变体，但目录已经存在可直接使用的跨时代商品：

| 时代 | 现有 good | 所需改动 |
|---|---|---|
| 石器/早期农业 | fur | 同时作为保暖与地位消费；加入 luxury variant |
| 探索 | spices | 加入 luxury variant，不需要先造“奢侈品”聚合 good |
| 青铜/古典以后 | jewelry | 增加早期金银匠方法；现代 jewelry_plant 成为升级 |
| 封建/探索以后 | beverages | 增加早期酿造方法；现有工厂改为后期升级 |

这会把奢侈品从 2 个变体扩到 4 个时代递进变体，同时只增加生产方式，不增加新 goods。汽车、家电、计算机已经分别属于 transport、durable_goods、recreation，不应为了“显得奢侈品多”重复接入所有需求。

### 5.3 纺织

当前工业链是 fiber -> yarn -> textile -> cloth -> clothing，而家庭链直接产出 cloth。`textile` 和 `cloth` 的战略含义重叠。

建议：

- 退休 `textile`，让行会织坊、纺织厂和合成纺织厂直接产出 cloth。
- 将 cotton_yarn、flax_yarn 归并为 yarn；棉、亚麻、羊毛保留为地域原料，由不同纺纱方法生产同一 yarn。
- 删除只承担 textile -> cloth 的 finishing 建筑，或仅在确实要表达染整时改成有独立效果的高质量布料方法。
- 保留 cloth -> clothing / footwear 的终端分支。

预计可减少 2-3 个 goods 和 2 座纯转手建筑，同时保留原料地理差异和蒸汽机械化。

### 5.4 书写、印刷与文化

本节原建议已被后续精简取代：`papyrus`、`parchment` 只有单一下游且没有独立消费、运输或战略价值，
现已连同纸草工坊、羊皮纸工坊删除。古典抄写室直接消费采集植物，修道院抄写室直接消费生皮，
共同产出“手抄本” `manuscripts`；探索时代以后由 `paper` 支撑印刷品 `printed_materials`，形成真正
可感知的手抄到印刷演进。

### 5.5 建材

- 合并 cut_stone 与 dressed_masonry 为 masonry；古典石工作坊和后期切石厂成为同一升级族并输出同一 good。
- 保留 bricks、lime、glass、cement、concrete，它们代表不同工艺和真实互补关系。
- 不要让现代 `construction_components` 同时强制消耗 concrete + steel + glass + bricks + cut_stone。改为多种时代方法：古典砖石法、蒸汽钢铁水泥法、现代预制混凝土法，均输出 construction_components。

### 5.6 冶金、机械与化工

这些链的物资区分总体比食物合理，主要问题是时代和启动配方，而不是需要大规模删 good。

- 铜/锡/青铜与铁/生铁/钢的分层应保留。
- wire 与 insulated_cable 的时代顺序应校正：先有金属 wire，后有橡胶/塑料绝缘 cable。
- `electrical_equipment` 的基础工场和现代工厂、`computers` 的数字工场和计算机厂应加入升级族。
- `industrial_chemicals` 可保留为战略聚合品，但必须有启蒙/蒸汽生产方式；后期电化学方法作为升级。
- 石油、天然气、炼油、润滑剂、石化、塑料和合成材料应从蒸汽末期到原子时代逐步展开，不能全部放到信息时代。
- 电子元件的多金属 BOM 可以保留；这是后期合理复杂度。若要简化，应优先减少同义 goods，而不是删除真正的关键材料约束。

### 5.7 服务建筑

当前原生建筑运行时要求物质输出，并未建模银行、学校、医院等服务结算。把这些建筑伪装成可库存 goods 会建立错误抽象。本轮只审计物质生产链；服务应在单独设计其效用、容量、覆盖范围和结算后再加入，不能用增加若干 `.tres` 的方式填密度。

## 6. 时代发现与生产方式路线

这里把“新发现什么”分成四类：自然资源发现、工艺发明、新产品、跨区域扩散。玉米和马铃薯并不是封建时代才在世界上存在；探索时代解锁的应是跨洋扩散和种植园方法，而不是作物本体。

| 时代 | 新发现/能力 | 新生产方式 | 对旧产业的影响 |
|---|---|---|---|
| 石器 | 火、打制工具、地表资源 | 采集、狩猎、火塘、手织 | 建立食物、衣物、工具的最低闭包 |
| 青铜 | 陶器、合金、定居农业和畜牧 | 窑烧、青铜工具、磨粉、烘焙、纺纱 | 工具替代提高采集效率；储存和加工开始分工 |
| 古典 | 书写、砌体、道路和水利组织 | 纸草/早期纸、石作、砖、石灰、玻璃、盐业 | 建筑材料和行政文化链加深 |
| 封建 | 行会、轮作、成熟手工业 | 水/风力磨坊、行会织造、裁缝、制鞋、酿造 | 家庭生产升级为作坊；农业和纺织效率提高 |
| 探索 | 远洋导航、印刷、跨洋扩散 | 船舶、印刷、种植园、保存食品、橡胶/棉/香料贸易 | 新原料进入旧食品和纺织配方，不强制新增同义成品 |
| 启蒙 | 实验科学、精密测量、标准化 | 科学仪器、精密工具、早期化工、标准零件 | 旧作坊获得高质量工具和可互换零件 |
| 蒸汽 | 焦炭、蒸汽动力、铁路 | 钢铁、蒸汽矿井、机械纺织、纸浆造纸、机械农业、早期油井 | 旧产业进入工厂升级族，增加煤、钢和机械作为互补品 |
| 电气 | 电力、电机、电化学、无线电 | 电气化工厂、铝、合成肥、制冷、内燃机、批量生产 | 电力/电机成为跨行业高效生产方式；食品保存和消费品扩张 |
| 原子 | 地质勘探、先进合金、核物理 | 战略矿物、石化/塑料、现代药品、核电、同位素 | 材料和能源约束更复杂，旧机械/化工链深化 |
| 信息 | 半导体、数字计算、网络 | 计算机、通信设备、数字控制生产 | 少增加原料，多给旧产业增加自动控制的高 tier 方法 |
| AI | 机器学习、自主控制 | 先进芯片、自主系统 | 重点应是跨行业自动化方法，而不是继续堆实体中间品 |

这条路线要求电气时代成为真正的中后期转折点。目前仅有 4 座电气建筑，是全目录最明显的时代空洞。

## 7. `legacy_modern_economy` 重分配

60 座 catch-all 建筑不应一次逐个随意前移，应按相互可启动的技术包迁移：

| 目标时代 | 迁移包 | 当前代表建筑 |
|---|---|---|
| 古典/封建 | 基础盐业、油脂、肥皂、金银工艺 | salt_collector、edible_oil_plant、soap_plant、早期 jewelry 方法 |
| 探索/启蒙 | 炸药、早期化工、药草制剂、精密零件 | explosives_plant、industrial_chemicals 的早期方法、pharmaceuticals 的早期方法 |
| 蒸汽 | 水泥/混凝土、机器零件、工业机械、农业机械、纸浆纸张、现代矿井、工具 | cement/concrete、machine_parts、industrial_machinery、agricultural_machinery、wood_pulp/paper、tools |
| 电气 | 电机、电线/绝缘线、电气设备、铝、电池、内燃机、汽车、油气和炼油 | electric_motor、wire、electrical_equipment、aluminum、batteries、engines、automobiles、oil/gas/refining |
| 原子 | 石化、塑料、合成纤维/橡胶、现代药品、合金、家电、电子元件 | petrochemicals、plastics、synthetics、pharmaceuticals、stainless steel、appliances、electronic_components |
| 信息 | 半导体、计算机、电信 | basic_semiconductor_fab、semiconductors_plant、digital_computer_workshop、computers_plant、telecom_equipment_plant |

迁移顺序必须按包执行，并在每个时代做零库存闭包测试。只改 tech tag、不改输入配方，会把同一个断层从信息时代搬到更早时代。

## 8. 推荐实施顺序

### Phase 0：先增加审计，不改玩法

1. 新增逐时代闭包测试：从零 goods 库存开始，累计授予每个时代科技，验证每座名义可用建筑至少有一条可启动路径。
2. 新增 goods 标签时代与最早生产者时代一致性检查。
3. 新增 category 使用审计，禁止只有分类名、没有任何替代输入消费者的“装饰 category”。
4. 新增强连通分量报告；允许反馈增益环，但每个环必须有一个此前时代可得的外部启动输入。

### Phase 1：P0 内容修复

1. 修复早期 paper、salt。
2. 修复农业机械和肥料的时代路径。
3. 打破 sulfur/explosives、oil/machinery 两个启动闭环。
4. 将食品包装改为合理的 containers 或移除不必要包装。

### Phase 2：简并生活资料

1. 合并 prepared staples。
2. 退休 grain_plant，解决 wheat_grain 的早期用途。
3. 合并 textile/cloth、yarn、cut stone/masonry 等同义层。
4. 清理只做一次无决策转手的建筑。
5. 用现有 fur/spices/jewelry/beverages 扩充 luxury。

### Phase 3：重建时代坡度

1. 分包拆解 `tech.legacy_modern_economy`。
2. 补齐 Enlightenment/Electrical 的生产方式。
3. 把同产出建筑加入升级族，确保新科技改变旧产业。
4. 信息/AI 时代以高 tier 方法为主，少增加平行中间品。

### Phase 4：仅在必要时扩展内容 API

如果多个 BuildingProfile 仍造成配方爆炸，再考虑把运行时已经存在的 InputCandidate CSR 暴露为内容层的显式候选及逐候选效率。该方案复用 native 选择逻辑，不新增平行经济权威。独立 `ProductionMethodProfile` 属于新子系统，需另行确认范围、UI、存档和迁移后再实施。

## 9. 验收标准

- 每个时代累计解锁后，名义可用建筑的零库存可启动率为 100%，或明确标记依赖进口且已有贸易前提。
- goods 的科技时代不早于可生产时代；若是知识可见但暂不可生产，必须使用不同字段表达，不能混用 `technology_tags`。
- 不再使用 `tech.legacy_modern_economy` 作为正式内容标签。
- 非 AI 的中间时代不能只新增 1-4 座建筑；电气时代必须承接电机、铝、油气、化工和量产升级。
- 新 goods 必须至少满足一项：地理稀缺、独立需求、独立储运、两个以上下游分支、关键科技/战略约束。
- 仅有相同用途、相同储运、相同需求的地域成品默认合并；地域差异优先留在原料与生产效率。
- category 必须表示真实可替代关系；多个输入槽继续表示真实互补关系，禁止把“可选配方中的所有材料”误写成全部必需。
- 每个反馈环都有从此前时代 goods 或自然资源进入的启动边。
- 生活资料链在早期保持 0-2 个商品输入；蒸汽以后逐步增加工具、能源和化学品，信息/AI 主要增加高质量生产方式而非横向重复 goods。

## 10. 与现有两份报告的差异

- 两份报告正确识别了 paper、salt、机械化农业、wheat_grain 和食物替代未使用。
- “信息时代 90+/133 座建筑”不符合当前工作区；正确值是 62 座，其中 60 座使用 `tech.legacy_modern_economy`。
- “category 替代使用率 30%”偏高；按输入槽看，除 tools 外为 0。
- 把四种主粮全部放入同一 category 会产生工艺错误；更稳妥的是保留地理原料、合并用途相同的成品，并只在合理工艺组内替代。
- 原报告只找到 5 个直接时代倒挂，没有覆盖零库存固定点，因此漏掉了 sulfur/explosives 与 oil/machinery 的启动闭环及其大范围级联。
- 奢侈品不应“保持现状”；优先复用现有 fur、spices、jewelry、beverages，而不是先新增 silk/perfume 等平行 goods。

## 11. 范围与架构说明

本审计没有修改任何 `.tres`、C++、GDScript、存档 schema、市场周期或默认参数。建议的 Phase 1-3 都可优先沿用现有 GoodProfile、BuildingProfile、category 输入、升级族、科技 bitset 和 NativeEconomyRuntime。服务经济和可切换生产方式仍是明确的后续设计项。
