## 0. 结论摘要

| 问题 | 判断 |
|---|---|
| 是否需要上调 T0 采集／狩猎产出 | **需要**。产值只有同层采集建筑基准线的 24%–36% |
| 是否所有食物建筑都要上调 | **不是**。只上调 T0 采集／狩猎／捕鱼；T0 野生谷物采集地、T1 及以上农田、加工类一律不动 |

## 2. 为什么必然"零剩余"——数学推导

定义 **NPE（营养人份）** = 一栋建筑满员一天的产出，能满足多少人一天的**该项**需求。
换算需经 `component_qty_per_need`（如 grain = 800，即 1 单位 grain 抵 0.8 need 单位；gathered_plants / game_meat = 1000，即 1:1）。

满员 1 岗的 NPE：

| 建筑 | 产出 | NPE | 覆盖项 |
|---|---|---|---|
| gathering_ground 采集营地 | 0.948 gathered_plants | **2.03** | 主食 |
| stone_age_hunting_camp 狩猎营地 | 0.310 game_meat | **2.03** | 蛋白质 |
| freshwater_fishing_camp 淡水捕鱼营地 | 0.310 fish | **2.03** | 蛋白质 |
| small_game_trapline 小型陷阱线 | 0.364 game_meat | 2.38 | 蛋白质 |
| wild_*_stand 野生采集地 ×4 | 0.948 谷物 | 2.53 | 主食 |
| fertile_soil_collector 菜蔬农场 | 1.32 vegetables | 5.17 | 蔬果 |
| subsistence_farm 自给农庄 | 0.556 grain + 0.556 vegetables | 3.67 | 主食 + 蔬果 |

设总人口 P、食物生产者 N。要满足 P 人份的**每一项**营养：

- 主食：需 `P / 2.03 = 0.493P` 个采集岗位
- 蛋白质：需 `P / 2.03 = 0.493P` 个狩猎／捕鱼岗位
- 蔬果：需 `P / 5.17 = 0.193P` 个菜蔬岗位
- 油脂：T0 无来源，`food_fat` 恒缺口

**合计 1.179P > P。**

即：**即使 100% 人口从事食物生产，仍缺约 18%，且油脂永远无法满足。** 这就是"只能自给自足、完全没有富余"的精确来源——当前标定隐含的假设就是全员务农、零剩余。

**蛋白质是最紧的瓶颈**：它只占总需求的 16.8%，却要求和主食（51.4%）一样多的岗位数，因为狩猎营地与采集营地的 NPE 完全相同（都是 2.03），而蛋白质的人均需求只有主食的 1/3。

要让非农人口达到 30%（α = 0.70），需将总岗位压到 0.70P，压缩系数 0.594 → **产出需 ×1.68**。
再叠加气候容量折损（cell 650 实测 `average_climate_capacity_q16` = 31,355 ≈ 47.8%）与业主不满员，实际建议 **×2.0 ~ ×2.5**。

## 3. 同层基准线的发现（关键旁证）

用 `default_price` 折算**每岗每日产值**，可绕开各 need 人均需求不同的干扰：

| 分组 | 建筑 | 产值/岗/天 |
|---|---|---|
| **T0 采集／狩猎（食物）** | 淡水捕鱼营地 | 3,100 |
| | 狩猎营地 | 3,964 |
| | 小型陷阱线 | 4,288 |
| | 采集营地 | 4,740 |
| T0 野生谷物采集地 | 野生玉米／稻／块茎／麦采集地 | 9,480 |
| **同层非食物采集** | 枯枝采集营地 | 13,000 |
| | 燧石采掘场 | 13,000 |
| | 草皮切割场 | 13,000 |
| | 芦苇收割营地 | 13,000 |
| | 毛石整理场 | 13,000 |
| | 土料挖掘坑 | 13,000 |
| | 野生韧皮纤维营地 | 13,000 |
| | 亚麻农场 | 13,650 |
| **T1 农田** | 退水玉米地 | 11,125 |
| | 雨养玉米田 | 12,795 |
| | 自给农庄 | 14,456 |
| | 旱作保水小麦田 | 16,480 |

**同层非食物采集建筑高度一致地落在 13,000**——这是一条明确的标定基准线（多为 2 岗／栋 × 1.3 单位／岗 × price 10,000）。

而 T0 食物采集／狩猎只有基准线的 **24%–36%**。双重打折：

1. **数量低**：采集营地 0.948／岗，非食物采集 1.3／岗（−27%）；狩猎营地 0.310／岗（−76%）
2. **单价低**：`gathered_plants` 的 `default_price = 5000`，其余采集品均为 10,000

**这直接解释了劳动力配置行为**：`economy_stagnation_cell650_diagnosis.md` 记录 cell 650 的 13 名 forager **全部**在 `bast_fiber_camp`（产值 13,000，产出 99.9% 丢弃）而非 `gathering_ground`（4,740，0 业主）。家庭按收入理性择业，食物岗位被系统性抛弃。

## 4. 分层上调建议

### A 类 — 必须上调（T0 采集／狩猎／捕鱼）

| id | 名称 | 现 `output_quantities_per_day` | 建议值 | 倍数 | 建议后产值/岗 |
|---|---|---|---|---|---|
| `gathering_ground` | 采集营地 | 948 | **1900** | ×2.0 | 9,500 |
| `stone_age_hunting_camp` | 狩猎营地 | 310, 36 | **780, 90** | ×2.5 | 9,960 |
| `freshwater_fishing_camp` | 淡水捕鱼营地 | 310 | **780** | ×2.5 | 7,800 |
| `marine_fish_collector` | 沿岸渔场（2 岗） | 620 | **1560** | ×2.5 | 7,800/岗 |
| `small_game_trapline` | 小型陷阱线 | 364, 20, 7 | **910, 50, 18** | ×2.5 | ≈10,700 |

### B 类 — 保持不动（避免压平农业革命的收益）

| 分组 | 理由 |
|---|---|
| `wild_maize_stand` / `wild_rice_marsh` / `wild_tuber_patch` / `wild_wheat_stand`（9,480） | 已在合理区间；上调后会逼近甚至越过 T1 农田（11,125），压平梯度 |
| T1 及以上农田（`subsistence_farm` 14,456、`three_field_smallholding`、`improved_smallholding`、`method_*` 系列） | 数值已明显高于基准线，且是"农业革命"的收益载体 |
| 加工类（`communal_hearth`、`staple_kitchen`、`bakery`、`slaughterhouse`、`creamery`） | 下游，随上游自动受益 |
| 全部非食物采集建筑 | 它们是基准线本身，一动就失去参照 |

上调后的梯度：采集营地 9,500 ≈ 野生谷物采集地 9,480 < T1 农田 11,125–16,480。农业革命仍有 17%–74% 的收益空间。

### C 类 — 配套必改（否则上调无效）

1. **零业主 → 零产能**：`capacity_q16` 随业主填充率缩放，0 业主 = 0 产出。cell 650 的 `gathering_ground` 是 0/7 业主，产出 0。数值翻倍对这类建筑**完全无效**。
   参考 `gdext/src/economy_runtime_building_employment.cpp:2090-2092` 的 `improvement` 闸门与 `investment.cpp:1552-1589` 的 `OWNER_VACANCY` 死锁。
2. **`ACTIVE_OWNER_VACANCY` 投资死锁**：格内不能新建食物建筑，恰恰因为现有的有业主空缺。逃生口 `survival_vacancy` 因 `executable_capacity_q16 = 0` 失效。
3. **气候容量偏低**：`average_climate_capacity_q16` 仅 47.8%，会吃掉一大部分上调收益。建议单独评估，不要靠放大产出掩盖。

## 5. 风险与验证

| 风险 | 说明 | 建议 |
|---|---|---|
| 野生资源天花板 | 狩猎／捕鱼用 `extract` 模式，`wild_game` 生态容量 1200、实测存量 1,865、安全产量 906/天。产出上调后这些建筑会更快撞上 `resource_stock_density_q16` 的密度折减，边际收益打折 | **首轮只改产出、不改 `resource_quantities_per_day`**，跑录数观察枯竭速度，再决定是否同步 |
| 采集营地不受此限 | `fertile_soil` 是 `capacity` 模式（不消耗储备），cell 650 存量 30,142，需求 500／栋，不构成瓶颈。故采集营地的上调效果最直接 | 若要保持"单位土地产出率"不变，可同步把 capacity 500 → 1000；若要直接制造富余，则不动 |
| `food_fat` 恒缺口 | T0 无油脂来源，`edible_oil_plant` 属后期。若希望早期需求可满足，需新增 T0 油脂源或下调 `food_fat` 权重 | 单独决策 |
| 只动了数值没动闸门 | 上调后若仍无业主，产出仍是 0 | **必须与 C 类同步修**，或先做"靶向重跑"验证 |

**建议验证路径**（沿用项目已有的最小可证伪方法）：
1. 先只改 A 类 5 个建筑的产出，重跑 cell 650 录数
2. 核对 `staple_food` / `protein` 是否满足、`worst_need_id` 是否离开 16、人口是否止跌
3. 观察 `wild_game` 枯竭速度，决定资源侧是否同步
4. 再处理 C 类劳动力闸门
