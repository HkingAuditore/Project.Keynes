## 4. 工作方式

1. 先跑审计，确认缺口（不凭印象加内容）。
2. 一个包 = 一个子代理 = 一个文件；简报与 API 见 `tmp/narrative_drafts/PACK_BRIEF.md`。
3. 子代理只写文件，不跑引擎、不改注册表；主代理统一注册、跑测试、修机制。
4. 测试全绿后更新本文档的「扩展后」列与 `narrative-event-web.md` 的节点表。

## 5. 下一轮建议（若还要扩）

- **同题异代**：同一骨架在 era 3 与 era 8 各写一版（例如"行会"与"工会"、"驿马"与"电报"），比继续平铺新题更省字数、重复感更低。
- **地区变体**：沿海 / 内陆 / 山地 / 河网四种地理，各配一套 2–3 条的地块事件。
- **人物回声**：让 `CAST` 里的名字跨包复现（同一个商人在三个时代出现），形成"地方志"感。
