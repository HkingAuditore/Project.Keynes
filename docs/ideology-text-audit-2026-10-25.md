# 理念文本与当前机制核对（2026-10-25）

本轮核对范围是正式卡池的 **113 张理念、339 个等级、280 个地块/国家/家族效果程序，以及 52 项可见羁绊与流派共鸣**。21 张因机制不完整而暂存的卡继续不进入卡池。名称保留主题表达，详情和效果只说明现有程序真正实施的行为。

完整玩家文本见 [理念卡面文案](../Project/project-keynes/docs/ideology-card-faces.md)，包含所有卡牌详情、三个等级、抽取条件和羁绊说明。

| 问题 | 核对结果与修正 |
| --- | --- |
| 住房需求 | `housing` 是家庭消费计划中的一个需求类别，显示名为“居住维护”，没有住宅容量、房租或住房建造模拟。卡牌统一写成“居住维护消费需求”，明确其指向消费倍率。 |
| 木材与原木混淆 | `lumber` 是木材，`logs` 才是原木。“轮伐”的来源条件和产出代价均改用实际商品名称。所有程序中的商品与需求名称读取当前目录。 |
| 共食扩大了来源种类 | 实际来源只有主产野味地块，不包含鱼和采集物。删除多余来源。 |
| 固定收益与累计上限混淆 | 共食、圈地、郊区化等明确区分每个来源的贡献、最多累计的来源数和最高加成；避免把满额加成写成无条件收益。 |
| 资源枯竭与商品短缺混淆 | `cell.depleted` 读取的是当地各商品中最高的市场短缺率。“生态均衡”改为货物最高短缺率至少 30%，不再称矿藏枯竭。资源丰度则明确为自然资源平均剩余比例。 |
| 不存在的代价 | 太空采矿摘要中的“资源消耗 +2%”没有对应指令，删除该承诺；真实的全国稀土耗用代价继续显示。 |
| 原始设计残留 | 113 张详情按现有程序重写。移除发钱、消除短缺、关税改革、污染、成本归零、房屋容量、永久压低死亡率等当前程序没有实施的承诺。 |
| 地租论候选文案 | 移除“地价上涨”“地主付得起地税”和“地价推高居住成本”等未实现因果；改写为代码实际配置的地主税负承受能力与大邑居住维护消费需求。 |
| 模糊的地块类型 | 明确宗族分支数量、分支威望、低人口地块、就业职业集中程度、部门产出占比、失业率、必需品短缺率、年均温和邻接人口合计等真实判据。 |
| 工人阶层支持度 | 实际输入是全国工人阶层满意度，明确全国口径，避免误读成当地理念支持度。单一职业占比明确采用当地就业人口口径。 |
| 小数个地块 | 盐铁专营、半导体等按实际线性系数和加成上限描述，不再要求“7.5 个”或“13.3334 个”地块。 |
| 条件改写被隐藏 | 展示抗生素、垂直农场、海水淡化、太空采矿、戍边、无人运输的实际筛选/邻域规则，明确只在理念槽中生效，并说明不改变地块本身属性。基础效果与规则改变分开列出。 |

| 气候损失和投入含义不清 | 区分寒冷/热害/旱灾/洪灾造成的生产损失、生产原料需求量和自然资源耗用。 |
| 显示层删减信息 | 移除独立的逐卡覆盖表，保留数量上限和所有效果行；长文本仍通过既有完整提示展示。 |

## 防止文案再次漂移

`generate_ideology_catalog.py:player_program_summary()` 同时读取程序的选择器、条件、指令、来源计数、线性系数与上限，以及当前商品/需求名称。旧的 `Prog.summary` 对正式卡只是作者备注；诊断夹具仍使用自己的备注。程序包含尚未审查的新字段组合时，生成器会在写入资源前失败。

条件改写的玩家说明也从真实改写条目生成，保存在该条目的展示备注中。`IdeologyCatalog` 只读生成文案，不再维护另一张逐卡摘要表。

回归验证包括 Python 的 10 项文案契约测试，以及 Godot 对全部 113 张卡、339 个等级、280 个效果程序和 52 项羁绊的遍历。测试检查每个效果程序都到达玩家可见文本，覆盖作用范围、真假代价、来源累计、词汇与机制对应，以及规则和一次性奖励没有被丢弃。

## 运行时边界

本轮只修改作者文本、生成器的展示文案编译和 GDScript 展示，不修改 C++ 权威状态、效果指令、选择器、触发条件、数值、抽取费用或卡池。三个生成目录去除展示字段后，逐字比较与修改前一致；PKID/PKEF/Modifier 协议及目录的可执行内容保持不变。

未增加住房、污染、发钱、关税或其他新模拟机制，也未发布暂存卡。
