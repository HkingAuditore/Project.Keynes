欢迎使用经济数值工作台

本工具会读取游戏项目里的产业链数据（建筑 / 物资 / 自然资源 / 职业 / 时代）， 并提供产业链图、建筑盈亏、居民消费和供需缺口预计算。

  • Chrome / Edge：点「选择项目根目录」选一次，之后每次打开自动重新扫描。
  • Firefox / Safari：用「选择文件夹」回退，每次打开手动选一次。

请选择仓库根目录（即含 Project/ 的那一层，例如 D:\Godot\ProjectKeynes\Project.Keynes）。工具只读不写。

模式
参考情景：默认价格、库存充足、财富/环境/族群系数为 1。居民替代品按当前 preference 分摊；建筑类目/候选投入按“默认价格 ÷ 效率”选择最低成本物资。该结果用于内容校准，不等同于含资金、库存和价格反馈的运行时模拟。
