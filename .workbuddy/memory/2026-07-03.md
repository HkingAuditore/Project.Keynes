- 评估 GodotShaders《2D top down oblique shadow》方案：其本质是 CanvasItem 上对 sprite 局部 height_map 做 per-pixel ray marching 阴影，适合建筑/物体投影到扩展承载 Sprite；不适合作为 Project.Keynes 全地图地形阴影主方案。建议借鉴 smoothstep soft threshold、透明区绘制阴影、alpha mask、低分辨率 shadow mask 思路；全地图应改为统一 terrain height/depth texture + screen/world UV + 低分辨率 directional shadow pass 或 C++ bake horizon/shadow。
- 地图阴影方案判断：确实需要 heightmap tracing/horizon 类算法，但不应在最终 terrain shader 全分辨率逐像素逐帧 trace。推荐优先生成低分辨率 R8 shadow mask，按太阳/地形变化更新；若太阳方向固定或分档，可在地图生成期 C++ bake shadow/horizon，主 shader 只采样 mask。
