# 植物与动物形状设计方案 - 快速总结

## 核心问题

当前游戏中，**植物和动物的形状辨识度严重不足**：
- 小麦、玉米、水稻、土豆看起来几乎一样
- 牛、羊、猪、马的形状差异也不明显
- 整体显得"平坦"、"卡通化"而非有质感

## 解决方案框架

### 三层设计系统

```
层级 1: 基础形状 SDF
├─ 植物 (form 0-7)
│  ├─ wheat_shape()    直立、细穗、尖头
│  ├─ corn_shape()     直立、粗穗、圆头、须根
│  ├─ rice_shape()     下垂、细穗、最高
│  └─ leafy_shape()    球形叶丛、矮胖
├─ 动物 (form 8-14)
│  ├─ horse_shape()    细长、长颈、竖耳
│  ├─ cattle_shape()   宽矮、有角
│  ├─ sheep_shape()    球形、蓬松、冲天毛
│  └─ pig_shape()      矩形、鼻子凸、卷尾
│
层级 2: 贴花系统
├─ 根须贴花（谷物）    4条向下放射
├─ 土壤贴花（叶菜）    不规则斑纹
├─ 毛发贴花（动物）    方向性纹理
└─ 花瓣贴花（花卉）    散落效果

层级 3: Shading 增强
├─ 细节法线           沿叶脉/毛发方向
├─ 毛发高光           各向异性高光
├─ 土壤着色           粗糙无光泽
└─ 透光效应           叶子 SSS 散射
```

## 动物形状关键特征

### 四大家畜对比表

| 特征 | 马 | 牛 | 羊 | 猪 |
|------|------|------|------|------|
| **高度** | ▲▲▲ | ▲▲ | ▲ | ▲ |
| **宽度** | 窄 | 宽 | 超宽 | 超宽 |
| **头部** | 细长 | 方大 | 圆 | 大方 |
| **特征** | 竖耳 | 有角 | 冲毛 | 鼻子 |
| **体型** | 细长 | 矮胖 | 球形 | 矩形 |
| **颜色** | 棕/黑 | 黑/花纹 | 白/灰 | 粉/黑 |
| **毛发** | 顺向 | 短毛 | 蓬松 | 光滑 |

### 识别要点

**马** ← 最"修长"的动物
```
  △ ← 竖耳（关键）
 /|\ ← 长颈（关键，40% 躯体高）
 | | ← 细长躯体
 | | ← 4 条细腿
```
**关键**：长颈 + 竖耳 = 马的唯一特征

**牛** ← 最"宽矮"且"有角"的动物
```
 >O< ← 角（关键！最重要特征）
 /|\ ← 宽大头部
 | | ← 短颈（几乎看不见）
 | | ← 宽厚躯体（55% 宽/高）
 | | ← 4 条粗腿
```
**关键**：角 + 宽矮体型 = 牛的标志特征

**羊** ← 最"蓬松"和"圆"的动物
```
  ^ ← 冲天毛（关键）
 ( ) ← 圆头
 OOO ← 蓬松球形躯体（65% 宽/高）
 | | ← 最短的腿
```
**关键**：球形 + 蓬松边缘 + 冲天毛 = 羊的全部特征

**猪** ← 最"宽矮"且"有鼻子"的动物
```
  o ← 鼻子凸出（关键）
 /|\ ← 头大
 | | ← 宽矮躯体（70% 宽/高）
~~~  ← 卷尾（加分特征）
 | |
```
**关键**：明显鼻子 + 矩形体型 = 猪的特征

## 实施策略

### Phase 1: 快速可视化（1天）

**不改 shader，只改参数**

```gdscript
# 在 resource_default.tres 调整
palette_saturation = 0.88      # 提升饱和度
luma_compress = 0.60           # 提升对比
```

**预期效果**：资源"跳"出地表 + 颜色差异更明显

### Phase 2: 形状设计（3-4天）

**逐个实现 8 种资源的 SDF**

```glsl
// 每种资源一个函数
vec2 wheat_shape(vec2 uv, float seed) { ... }
vec2 corn_shape(vec2 uv, float seed) { ... }
vec2 rice_shape(vec2 uv, float seed) { ... }
// ...
vec2 horse_shape(vec2 uv, float seed) { ... }
vec2 cattle_shape(vec2 uv, float seed) { ... }
// ...
```

**预期效果**：8 种资源可一眼区分（vs 现在的"全是一样的"）

### Phase 3: Shading（1-2天）

**添加细节法线 + 高光 + 阴影**

```glsl
// 毛发/叶脉方向
vec3 detail_normal = get_detail_normal(uv, family, form, seed);

// 各向异性高光
vec3 highlight = anisotropic_highlight(light_dir, view_dir, detail_normal);

// 多层阴影
float shadow = ground_ao * terrain_shadow * self_shadow;
```

**预期效果**：资源不再"平坦"，有质感和深度

**零额外纹理采样** ✓
- 只增加 ALU（数学运算）
- 复用现有 GI/horizon 数据

**性能增长**：


## 常见疑虑解答

### Q: 这样改会不会显得太"真实"？
A: 不会。我们只改 2D impostor 的轮廓和着色，仍然是"简洁风格"，只是可识别了。

### Q: 如果玩家不喜欢怎么办？
A: Phase 1（参数改动）是零风险的，可以立即回滚。Phase 2+ 可选。

### Q: 这会不会破坏现有游戏美学？
A: 相反，让资源更易辨识反而增强了游戏的"可读性"。参考对比：
- 好游戏：UI 清晰、信息易读
- 差游戏：所有元素看起来一样，玩家分不清

### Q: 可以只做一部分吗？
A: 完全可以。推荐先做 Phase 1（参数），然后做最关键的 2-3 种资源（如：小麦、玉米、牛），其他后续。

### Q: 如何说服美术/策划这个改动？
A: 
1. **对比截图**：优化前后的艺术审查图
2. **玩家反馈**："我分不清不同的作物"
3. **设计意图**：游戏已经有 51 种资源，需要视觉上可区分
