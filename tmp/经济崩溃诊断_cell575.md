## 二、本格在跑的 9 种建筑（全部为石器时代/采集型）

`公共火塘 / 燧石采掘场 / 采集营地 / 家庭织造棚 / 石器打制工坊 / 锯木场 / 狩猎营地 / 采石场 / 伐木场`

逐一审视这 9 个 `.tres`：**全部 `employee_profession_ids = PackedStringArray()`、`employee_slots_per_building = PackedInt64Array()`** —— 即
**每个建筑只有 1 个业主槽、0 个雇员槽**。产出为 `gathered_plants / game_meat / flint / cloth / chipped_stone_tools / lumber / raw_stone / logs / processed_food`。

这是一个**没有任何农场、任何渔场、任何面包坊的新石器聚落**。蛋白质来源**只有狩猎（game_meat）和鱼（fish）**，而本格 `marine_fish` 资源储量恒为 **0** → 渔业在物理上不可能。

## 三、根因（按重要性）

### P0-1. 结构性大规模失业（内容/拓扑问题）
本格 9 种建筑 **雇员槽 = 0**。全部就业 = 当业主。非业主人口（末期 70/76 = 92%）**从设计上就没有任何收入来源**。
- 校验：epoch 23 本格失业 125、非商户人口 145 → 就业非商户 ≈ 20；同期 9 种建筑 `filled_owner` 之和 ≈ 21，`employee_filled` 恒为 0。即「就业人口 ≈ 业主数，雇员恒为 0」。
- 结论：人口爆炸式失业不是偶发，是**新石器建筑组的内容缺陷**。

### P0-2. 蛋白质供给结构性断裂（内容/资源问题）
- `fish`：**整段模拟 shortage=65535、household_available_stock=0**（价格 ~100k），因为 `marine_fish` 储量恒为 0 → 鱼永远买不到。
- `game_meat`：day 215 尚有 household_avail=1695，到 day 2590 跌到 stock=1、shortage=65535 → 狩猎随建筑停摆而消失。
- `gathered_plants`（蔬菜/采集食）反而充裕（末期 stock≈67k、价格 500）→ **失败的是蛋白质，不是全部食物**。
- 狩猎链脆弱：`狩猎营地` 需 `chipped_stone_tools`（来自 `石器打制工坊`，需 `flint` 来自 `燧石采掘场`）。单点断供即级联停摆。

### P0-3. 业主成批弃楼引发死亡螺旋（原生公式/内容）
- `filled_owner` 从 day 5 的 146 跌到 day 115 的 ≈21（同期首次出现死亡）。建筑关闭 → 产出（食物/货物）消失 → 业主失去收入与所产食物 → 满意度崩 → 更多死亡/弃楼。
- `采石场 / 伐木场` 早期即出现 `operating_state=1`（亏损停摆）、`severe_loss_cycles=3`。说明**原始采集/加工建筑在现行成本-利润模型下是亏损的**，触发自动关停 → 上游 `tools` 断供 → 下游（狩猎）连锁瘫痪。**需核查原生建筑盈亏与关停逻辑**。

### P1-1. 商人财富虹吸、居民购买力枯竭（原生公式问题）
1 户商人资金从 78M 单调增长到 **110M**；非商户资金从 16.7M 缩到 **387,500**（人均 ≈5,100）。而蛋白质单价 ~100k–160k。居民**即便有货也买不起**；且货本就为 0。典型的「商人零售毛利净累积 + 失业居民无收入」模式（skill 明确点名的常见病）。

### P1-2. 资源透支（内容/原生平衡）
- `timber` 28,413 → **88**（−99.7%）
- `fertile_soil` 346,802 → **23,523**（−93%）
- `stone / flint / clay / coal / iron_ore / copper_ore` 基本不变（储量巨大）
→ 砍伐/采集类建筑在耗尽有限资源，缺乏再生平衡。

## 四、时间因果链

1. **day 5–115**：聚落 ~147 人，但建筑组为纯新石器、0 雇员槽。仅少数人为业主，其余**结构性失业**；原始建筑在成本模型下微利/亏损。
2. **day ~115（epoch 23）**：业主成批弃楼（filled_owner 146→21），建筑产能/产出骤降；**首次人口下降**；失业已达 125/146。
3. **day ~215（epoch 43）**：平均满意度跌破 0.5；`game_meat` 可用量见顶后回落，`fish` 永久短缺 → **蛋白质需求无法满足**成为全员 worst_need（始终为「食品」）。
4. **day 400–1400**：利用率短暂回弹但蛋白质从未恢复；失业恒在 70/76；商人资金突破 100M。
5. **day 1600+（epoch 320+）**：产能利用率永久跌到 ~14% 并锁死；经济实质死亡。
6. **day 2590**：人口 77（−48%）、满意度 0.519、利用率 14%、商人 110M vs 居民 387k。

## 五、责任边界判定

- **主要是内容/配置 + 早期拓扑问题**：新石器建筑组无雇员槽、无可持续食物生产（农场/渔场），蛋白质结构性不可得。
- **伴生原生公式问题**：① 商人零售毛利净累积、居民购买力枯竭；② 原始建筑盈亏/关停逻辑导致成批弃楼与级联断供；③ 资源再生平衡缺失。
- **非账本 bug**：守恒误差全 0。

## 六、P0/P1 修复清单

**P0（阻断崩溃）**
1. 给早期建筑加雇员槽，或把业主利润 redistribute 给住户，或将出生/迁入人口上限对齐业主槽位数 → 消除结构性失业。
2. 为本格补充可行蛋白质源：在 `marine_fish>0` 处开放渔场，或加入带再生的可持续狩猎 / 早期畜牧（pasture）→ 解除蛋白质死结。
3. 打断脆弱单点供应链：为狩猎/加工加缓冲库存或输入替代，避免一个建筑关停级联瘫痪整条链。

**P1（防止复发）**
4. 核查并下调商人零售毛利净累积、提升住户购买力（工资/业主分红），避免「商人 110M / 居民 5k」的极端分化。
5. 调整 `timber / fertile_soil` 的采集速率与再生速率，防止有限资源被抽干。
6. 排查 `采石场 / 伐木场` 等原始采集建筑为何亏损停摆（输入 `tools` 成本 vs 产出价值），修正盈亏/关停阈值。

## 七、建议的下一步核验
- 在原生侧打印**建筑关停触发条件**与**业主弃楼条件**（是亏损自动关、还是满意度低 emigration），确认 P0-3 的触发机制。
- 打印住户**收入构成**（业主分红 vs 工资 vs 商户采购支出），确认 P1-1 的虹吸路径。
- 确认 `marine_fish` 储量=0 是否本格常态（若是，则鱼类需求应被消费计划剔除，否则应开放渔场）。
